一、市场集中度分析

市场集中度概述

市场集中度是衡量市场竞争程度的重要指标，反映了市场份额在企业之间的分布情况。常用的衡量指标包括CRn指数和HHI指数。

CRn指数计算

CRn指数是指市场上前n家企业的市场份额之和。例如CR4表示前4家企业的市场份额总和。

CRn = Σ(第i家企业市场份额)，i=1到n

# 计算CRn指数 import pandas as pd # 市场份额数据（按降序排列） market_data = { '企业': ['企业A', '企业B', '企业C', '企业D', '其他'], '市场份额(%)': [35, 25, 15, 10, 15] } df = pd.DataFrame(market_data) # 计算CR4 cr4 = df['市场份额(%)'].iloc[:4].sum() # 计算CR3 cr3 = df['市场份额(%)'].iloc[:3].sum() # 计算HHI指数 hhi = sum([(share / 100) ** 2 for share in df['市场份额(%)']]) * 10000 print(f"CR3: {cr3}%") print(f"CR4: {cr4}%") print(f"HHI指数: {hhi:.2f}")
市场集中度判定标准
低集中
HHI < 1500
中集中
1500 ≤ HHI < 2500
高集中
HHI ≥ 2500
知识点测验

CR4指数表示什么？

市场上所有企业的市场份额之和
市场上前4家企业的市场份额之和
市场上前4个行业的市场份额之和
市场上排名第4家企业的市场份额

解析：CR4指数表示市场上前4家企业的市场份额之和，用于衡量市场集中度。

二、PEST分析法

PEST框架概述

PEST分析是一种宏观环境分析方法，用于评估政治(Political)、经济(Economic)、社会(Social)和技术(Technological)因素对企业的影响。

PEST分析框架

政治因素

政策法规、税收政策、政府稳定性

经济因素

GDP增长、通货膨胀、利率汇率

社会因素

人口结构、消费习惯、文化趋势

技术因素

技术创新、数字化转型、AI发展

PEST分析实战

以下是使用Python进行PEST分析数据整理和可视化的示例：

# PEST分析数据整理 import pandas as pd # 创建PEST分析数据 pest_data = { '维度': ['政治', '政治', '经济', '经济', '社会', '社会', '技术', '技术'], '因素': ['数据隐私法规', '税收政策', '消费升级', '利率变化', '老龄化趋势', '线上消费习惯', 'AI技术发展', '云计算普及'], '影响程度': [3, 2, 4, 2, 3, 4, 5, 4], '趋势': ['负向', '中性', '正向', '负向', '负向', '正向', '正向', '正向'] } df = pd.DataFrame(pest_data) # 按维度分组统计 pest_summary = df.groupby('维度').agg({ '影响程度': 'mean', '因素': 'count' }).rename(columns={'因素': '因素数量'}) print(pest_summary.round(2))

提示：PEST分析结果需要结合企业自身情况进行解读，同一个因素对不同企业可能产生不同影响。

知识点测验

PEST分析中的"S"代表什么？

Political（政治）
Economic（经济）
Social（社会）
Technological（技术）

解析：PEST分析中的四个维度分别是Political（政治）、Economic（经济）、Social（社会）、Technological（技术）。

三、SWOT分析量化

SWOT分析概述

SWOT分析是一种战略分析工具，用于评估企业的优势(Strengths)、劣势(Weaknesses)、机会(Opportunities)和威胁(Threats)。

SWOT分析矩阵

优势(S)

核心技术、品牌优势、人才储备

劣势(W)

资金不足、技术落后、管理薄弱

机会(O)

市场增长、政策支持、技术突破

威胁(T)

竞争加剧、政策变化、技术替代

SWOT量化方法

通过赋予权重和评分，将定性分析转化为定量结果，便于比较和决策。

# SWOT量化分析 import pandas as pd # SWOT因素数据 swot_data = { '维度': ['优势', '优势', '劣势', '劣势', '机会', '机会', '威胁', '威胁'], '因素': ['品牌知名度', '技术研发能力', '资金压力', '人才流失', '市场需求增长', '政策支持', '竞争对手进入', '原材料涨价'], '权重': [0.3, 0.2, 0.25, 0.15, 0.2, 0.3, 0.25, 0.2], '评分': [8, 7, 5, 4, 8, 9, 6, 5] } df = pd.DataFrame(swot_data) # 计算加权得分 df['加权得分'] = df['权重'] * df['评分'] # 按维度汇总 swot_summary = df.groupby('维度').agg({ '加权得分': 'sum' }) print(swot_summary)

注意：SWOT量化结果依赖于权重和评分的主观设定，不同的评估者可能得出不同结果，需要多人评估取平均值。

知识点测验

SWOT分析中的"O"代表什么？

Strengths（优势）
Weaknesses（劣势）
Opportunities（机会）
Threats（威胁）

解析：SWOT分析包括Strengths（优势）、Weaknesses（劣势）、Opportunities（机会）和Threats（威胁）。
