项目7：库存ABC分析

中级
预计时长：40分钟
技术栈：Python + Pandas + Matplotlib
数据量：50种商品

分析技巧

sort_values() - 按值排序
cumsum() - 计算累计值
cumulative_ratio - 累计占比计算
apply(classify) - 批量分类
twinx() - 双轴图绘制

学习目标

理解ABC分析原理
掌握帕累托法则应用
学会累计占比计算
绘制帕累托分析图

管理策略

A类: 重点管理，每日盘点，保持充足库存
B类: 常规管理，周度盘点
C类: 简化管理，月度盘点，可适当精简SKU

项目背景

ABC分析法是一种基于帕累托法则（80/20原则）的库存管理方法，将商品按销售额贡献分为三类，实现差异化管理。

商品销售数据

商品ID商品名单价(元)年销量年销售额(元)

学习内容

ABC分类核心概念

A类商品

~70%
销售额占比
重点管理 · 每日盘点

B类商品

~20%
销售额占比
常规管理 · 周度盘点

C类商品

~10%
销售额占比
简化管理 · 月度盘点
帕累托法则（二八定律）
80%的销售额通常由20%的商品贡献。通过识别这20%的关键商品，可以集中资源实现最大效益。
小贴士
ABC分类后，A类要每日盘点，C类可以月度盘点，管理成本大不同！A类商品占用80%精力的同时贡献70%销售额。
常见错误
只看销售额不看利润！有些C类商品利润率高反而值得重视，建议结合利润贡献进行多维度分类。

代码示例1：计算每种商品的年销售额，降序排列

import pandas as pd

# 计算年销售额
df['annual_sales'] = df['price'] * df['annual_quantity']

# 按销售额降序排列
df_sorted = df.sort_values('annual_sales', ascending=False).reset_index(drop=True)
print(df_sorted[['product_name', 'annual_sales']])

代码示例2：计算累计占比，分类为A/B/C

# 计算总销售额
total_sales = df_sorted['annual_sales'].sum()

# 计算累计销售额和累计占比
df_sorted['cumulative_sales'] = df_sorted['annual_sales'].cumsum()
df_sorted['cumulative_ratio'] = df_sorted['cumulative_sales'] / total_sales * 100

# ABC分类
def classify_abc(ratio):
    if ratio <= 70:
        return 'A'
    elif ratio <= 90:
        return 'B'
    else:
        return 'C'

df_sorted['abc_class'] = df_sorted['cumulative_ratio'].apply(classify_abc)
print(df_sorted[['product_name', 'annual_sales', 'cumulative_ratio', 'abc_class']])

代码示例3：绘制帕累托图（柱状+折线双轴图）

import matplotlib.pyplot as plt

# 绘制帕累托图
fig, ax1 = plt.subplots(figsize=(12, 6))

# 柱状图：销售额
ax1.bar(range(len(df_sorted)), df_sorted['annual_sales'], color='#3b82f6', alpha=0.7, label='销售额')
ax1.set_xlabel('商品排名')
ax1.set_ylabel('销售额(元)', color='#3b82f6')

# 折线图：累计占比
ax2 = ax1.twinx()
ax2.plot(range(len(df_sorted)), df_sorted['cumulative_ratio'], color='#ef4444', marker='o', linewidth=2, label='累计占比%')
ax2.set_ylabel('累计占比(%)', color='#ef4444')

# 添加80%参考线
ax2.axhline(y=80, color='gray', linestyle='--', alpha=0.5)

plt.title('ABC分析帕累托图')
plt.show()
