项目8：广告投放ROI分析

中级
预计时长：35分钟
技术栈：Python + Pandas
数据量：5个渠道数据

项目背景

广告投放是企业获取客户的重要手段，但不同渠道的效果和成本差异很大。ROI（投资回报率）是衡量广告效果的核心指标，帮助企业优化广告预算分配。

  • ROI公式：ROI = (广告带来的收益 - 广告成本) / 广告成本 × 100%
  • CPC（Cost Per Click）：每次点击成本
  • CPM（Cost Per Mille）：每千次展示成本
  • 转化率：点击到成交的转化比例

本项目分析不同广告渠道的效果，找出最优投放渠道。

import pandas as pd

# 广告投放数据
data = [
    {"channel": "抖音", "cost": 50000, "impressions": 500000, "clicks": 25000, "orders": 500, "revenue": 150000},
    {"channel": "微信", "cost": 30000, "impressions": 300000, "clicks": 12000, "orders": 360, "revenue": 108000},
    {"channel": "百度", "cost": 40000, "impressions": 400000, "clicks": 16000, "orders": 280, "revenue": 84000},
    {"channel": "微博", "cost": 20000, "impressions": 200000, "clicks": 8000, "orders": 160, "revenue": 48000},
    {"channel": "B站", "cost": 25000, "impressions": 250000, "clicks": 10000, "orders": 200, "revenue": 60000},
]

df = pd.DataFrame(data)

print("=" * 60)
print("【第1步】计算CPC和CPM")
df['CPC'] = (df['cost'] / df['clicks']).round(2)
df['CPM'] = (df['cost'] / df['impressions'] * 1000).round(2)
print(df[['channel', 'CPC', 'CPM']].to_string(index=False))

print("\n" + "=" * 60)
print("【第2步】计算转化率")
df['conversion_rate'] = (df['orders'] / df['clicks'] * 100).round(2)
print(df[['channel', 'clicks', 'orders', 'conversion_rate']].to_string(index=False))

print("\n" + "=" * 60)
print("【第3步】计算ROI")
df['profit'] = df['revenue'] - df['cost']
df['ROI'] = ((df['revenue'] - df['cost']) / df['cost'] * 100).round(2)
print(df[['channel', 'cost', 'revenue', 'profit', 'ROI']].to_string(index=False))

print("\n" + "=" * 60)
print("【第4步】按ROI排序，找出最优渠道")
df_sorted = df.sort_values('ROI', ascending=False)
print("\n渠道ROI排名：")
for idx, row in df_sorted.iterrows():
    status = "✅ 盈利" if row['ROI'] > 0 else "❌ 亏损"
    print(f"  {row['channel']}: ROI={row['ROI']:.1f}% {status}")

print("\n" + "=" * 60)
print("【第5步】预算优化建议")
best_channel = df.loc[df['ROI'].idxmax(), 'channel']
worst_channel = df.loc[df['ROI'].idxmin(), 'channel']
print(f"  - 推荐增加预算：{best_channel}")
print(f"  - 建议减少预算：{worst_channel}")
print(f"  - 平均ROI: {df['ROI'].mean():.2f}%")

ROI分析技巧

CPC = 广告成本 / 点击次数
CPM = 广告成本 / 展示次数 × 1000
转化率 = 订单数 / 点击数 × 100%
ROI = (收益-成本)/成本 × 100%
优化策略 - 增加ROI高渠道预算
