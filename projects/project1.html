项目1：销售数据清洗

初级
预计时长：30分钟
技术栈：Python + Pandas
数据量：10条记录

项目背景

某电商平台的销售数据存在多种数据质量问题，需要进行清洗处理后才能进行后续分析。

原始数据集

订单ID 日期 商品名 数量 单价 地区

学习内容

小贴士
数据清洗占数据分析80%的时间，干净的DataFrame可以调用 .info() 检查每列的非空值和数据类型。
常见错误
直接删除含缺失值的行会丢失大量信息！应先分析缺失原因。

代码示例1：查看缺失值分布

使用 .isnull().sum() 查看每列的缺失值数量：

import pandas as pd

# 查看缺失值分布
print(df.isnull().sum())

代码示例2：填充缺失值

使用 .fillna() 填充缺失值：

# 用"未知商品"填充商品名缺失
df['商品名'] = df['商品名'].fillna('未知商品')

# 用均值填充单价缺失
df['单价'] = df['单价'].fillna(df['单价'].mean())

代码示例3：统一日期格式

使用 pd.to_datetime() 统一日期格式，添加 errors='coerce' 参数处理无法解析的日期：

# 统一日期格式为 YYYY-MM-DD
df['日期'] = pd.to_datetime(df['日期'], errors='coerce').dt.strftime('%Y-%m-%d')

清洗技巧

isnull().sum() - 查看缺失值分布
fillna() - 填充缺失值
df[条件] - 筛选符合条件的行
pd.to_datetime() - 转换日期格式
dt.strftime() - 格式化日期输出
