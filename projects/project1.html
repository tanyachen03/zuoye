项目1：销售数据清洗

初级
预计时长：30分钟
技术栈：Python + Pandas
数据量：100条记录

项目背景

某电商平台的销售数据存在多种数据质量问题，需要进行清洗处理后才能进行后续分析。主要问题包括：

  • 缺失值：部分订单的金额、客户信息存在缺失
  • 异常值：订单金额出现负数或极端值
  • 格式问题：日期格式不统一，需要标准化
  • 重复记录：存在少量重复的订单数据

原始数据集

订单ID 客户名称 产品类别 订单日期 订单金额 订单数量

清洗任务

请完成以下数据清洗操作：

  • 处理订单金额的缺失值（用均值填充）
  • 将订单金额的负值转为正值
  • 删除金额超过10000的异常记录
  • 统一日期格式为 YYYY-MM-DD
  • 删除重复的订单记录
  • 输出清洗后的数据统计信息

import pandas as pd

# 原始销售数据（包含各种问题）
data = [
    {"order_id": "ORD001", "customer": "张三", "category": "电子产品", "date": "2024-01-15", "amount": 2999, "quantity": 1},
    {"order_id": "ORD002", "customer": "李四", "category": "服装", "date": "2024/01/16", "amount": 399, "quantity": 2},
    {"order_id": "ORD003", "customer": "王五", "category": "电子产品", "date": "2024-01-17", "amount": None, "quantity": 1},
    {"order_id": "ORD004", "customer": "赵六", "category": "家居", "date": "2024-01-18", "amount": -500, "quantity": 3},
    {"order_id": "ORD005", "customer": "钱七", "category": "服装", "date": "2024-01-19", "amount": 699, "quantity": 1},
    {"order_id": "ORD006", "customer": "孙八", "category": "电子产品", "date": "2024-01-20", "amount": 15000, "quantity": 1},
]

df = pd.DataFrame(data)

print("=" * 60)
print("【第1步】处理缺失值（用均值填充）")
mean_amount = df['amount'].mean()
df['amount'] = df['amount'].fillna(mean_amount)
print(f"  - 金额均值: {mean_amount:.2f}")
print(df.to_string(index=False))

print("\n【第2步】处理负值（取绝对值）")
df['amount'] = df['amount'].abs()
print(df.to_string(index=False))

print("\n【第3步】删除异常值（金额>10000）")
df = df[df['amount'] <= 10000]
print(f"  - 删除了 1 条异常记录")
print(df.to_string(index=False))

print("\n【第4步】统一日期格式")
df['date'] = pd.to_datetime(df['date']).dt.strftime('%Y-%m-%d')
print(df.to_string(index=False))

print("\n【第5步】删除重复记录")
df = df.drop_duplicates(subset=['order_id'])
print(df.to_string(index=False))

print("\n" + "=" * 60)
print("【最终统计】")
print(f"  - 有效记录数: {len(df)}")
print(f"  - 总销售额: {df['amount'].sum():.2f}")
print(f"  - 平均订单金额: {df['amount'].mean():.2f}")
print(f"  - 最高订单金额: {df['amount'].max():.2f}")
print(f"  - 最低订单金额: {df['amount'].min():.2f}")

清洗技巧

fillna() - 使用指定值填充缺失值
abs() - 取数值的绝对值
drop_duplicates() - 删除重复记录
to_datetime() - 转换日期格式
dt.strftime() - 格式化日期输出
