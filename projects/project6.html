项目6：客户生命周期价值(CLV)预测

高级
预计时长：60分钟
技术栈：Python + Pandas
数据量：100个用户

项目背景

客户生命周期价值（Customer Lifetime Value, CLV）是衡量客户在整个生命周期内为企业带来总收益的核心指标。

用户消费数据

用户ID用户名注册日期首次购买最近购买购买次数总金额(元)

学习内容

CLV核心公式
CLV = 平均购买金额 × 年购买频率 × 平均客户寿命（年）
CLV = Average Order Value × Annual Purchase Frequency × Customer Lifespan

获客成本预算

根据CLV制定合理的获客成本上限，确保投资回报率

VIP客户识别

识别高价值客户，提供差异化服务和精准营销

小贴士
CLV大于获客成本3倍以上的客户群，才是健康的商业模式！这意味着每投入1元获客成本，能获得3元以上的回报。
常见错误
简单取所有客户的平均值，忽略了不同渠道/地区客户的巨大差异！应该按细分群体分别计算CLV。

代码示例1：按用户分组计算购买总金额和天数

import pandas as pd
from datetime import datetime

# 模拟用户消费数据
data = [
    {"user_id": "U001", "first_date": "2024-01-15", "last_date": "2024-06-15", "total_amount": 8500, "orders": 5},
    {"user_id": "U002", "first_date": "2024-02-01", "last_date": "2024-06-01", "total_amount": 3200, "orders": 2},
]

df = pd.DataFrame(data)
df['first_date'] = pd.to_datetime(df['first_date'])
df['last_date'] = pd.to_datetime(df['last_date'])

# 计算客户生命周期天数
df['lifetime_days'] = (df['last_date'] - df['first_date']).dt.days + 1

# 计算平均订单价值
df['avg_order_value'] = df['total_amount'] / df['orders']

print(df[['user_id', 'total_amount', 'orders', 'lifetime_days', 'avg_order_value']])

代码示例2：估算年均价值和预测寿命

# 计算年均购买频率
analysis_date = datetime(2024, 6, 30)
df['observation_days'] = (analysis_date - df['first_date']).dt.days
df['annual_frequency'] = (df['orders'] / df['observation_days']) * 365

# 假设平均客户寿命为3年（可调整）
avg_lifespan_years = 3

# 计算CLV
df['CLV'] = df['avg_order_value'] * df['annual_frequency'] * avg_lifespan_years

print(df[['user_id', 'avg_order_value', 'annual_frequency', 'CLV']].sort_values('CLV', ascending=False))
进阶模型：BG/NBD概率模型

BG/NBD模型（Beta-Geometric/Negative Binomial Distribution）是客户行为预测的经典模型。

核心原理：

  • 假设客户活跃时，每次购买服从泊松分布
  • 客户"失活"（停止购买）服从几何分布
  • 失活率在不同客户间服从Beta分布

可预测每个客户在未来的购买次数和流失概率，实现更精准的CLV预测。

]

df = pd.DataFrame(data)
df['first_date'] = pd.to_datetime(df['first_date'])
df['last_date'] = pd.to_datetime(df['last_date'])
analysis_date = datetime(2024, 6, 30)

# 第1步：计算基础指标
print("=" * 70)

df['lifetime_days'] = (df['last_date'] - df['first_date']).dt.days + 1

df['avg_order_value'] = df['total_amount'] / df['orders']

# 第2步：计算CLV
print("\n" + "=" * 70)
print("【第2步】计算CLV（假设平均客户寿命3年）")
avg_lifespan_years = 3
df['CLV'] = df['avg_order_value'] * df['annual_frequency'] * avg_lifespan_years
df['CLV'] = df['CLV'].round(2)

print("\nCLV预测结果：")
clv_result = df[['user_name', 'avg_order_value', 'annual_frequency', 'CLV']].sort_values('CLV', ascending=False)
print(clv_result.to_string(index=False))

# 第3步：找出TOP 20%高价值客户
print("\n" + "=" * 70)
print("【第3步】TOP 20%高价值客户分析")
n_customers = len(df)
top_20_percent = int(n_customers * 0.2) if n_customers * 0.2 > 1 else 1

df_sorted = df.sort_values('CLV', ascending=False).reset_index(drop=True)
top_customers = df_sorted.head(top_20_percent)
other_customers = df_sorted.iloc[top_20_percent:]

print(f"TOP 20% 客户数: {top_20_percent}")

top_clv_sum = top_customers['CLV'].sum()

print(f"TOP 20%客户CLV总和: {top_clv_sum:,.2f} 元")
print(f"全部客户CLV总和: {total_clv_sum:,.2f} 元")

print("\n【结论】")
print("TOP 20%高价值客户的CLV总和占比远超其人数占比，具有重要的商业价值！")
