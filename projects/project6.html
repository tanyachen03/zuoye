项目背景

客户生命周期价值（Customer Lifetime Value, CLV）是衡量客户在整个生命周期内为企业带来总收益的关键指标。准确的CLV预测可以帮助企业：

  • 识别高价值客户，优化资源分配
  • 制定精准的客户获取成本预算
  • 评估客户关系投资回报
  • 预测未来收入，制定业务计划

本项目使用简化的CLV计算公式，基于历史消费数据进行预测。

分析任务

请完成以下CLV预测分析：

  • 计算每个客户的平均订单价值
  • 计算客户的平均购买频率（购买次数/月）
  • 计算客户的生命周期（月数）
  • 使用公式 CLV = 平均订单价值 × 购买频率 × 生命周期 预测CLV
  • 按CLV值对客户进行分层

import pandas as pd
from datetime import datetime

# 用户消费历史数据
data = [
    {"user_id": "U001", "user_name": "张三", "first_date": "2024-01-15", "last_date": "2024-04-15", "total_orders": 6, "total_amount": 12500},
    {"user_id": "U002", "user_name": "李四", "first_date": "2024-02-01", "last_date": "2024-04-10", "total_orders": 3, "total_amount": 3800},
    {"user_id": "U003", "user_name": "王五", "first_date": "2024-01-01", "last_date": "2024-04-20", "total_orders": 8, "total_amount": 18900},
    {"user_id": "U004", "user_name": "赵六", "first_date": "2024-03-01", "last_date": "2024-04-25", "total_orders": 2, "total_amount": 1500},
    {"user_id": "U005", "user_name": "钱七", "first_date": "2024-01-10", "last_date": "2024-04-28", "total_orders": 5, "total_amount": 9800},
]

df = pd.DataFrame(data)
df['first_date'] = pd.to_datetime(df['first_date'])
df['last_date'] = pd.to_datetime(df['last_date'])
analysis_date = datetime(2024, 4, 30)

print("=" * 60)
print("【第1步】计算基础指标")
df['avg_order_value'] = df['total_amount'] / df['total_orders']
df['lifetime_months'] = ((df['last_date'] - df['first_date']).dt.days / 30) + 1
df['purchase_frequency'] = df['total_orders'] / df['lifetime_months']
print(df[['user_name', 'avg_order_value', 'lifetime_months', 'purchase_frequency']].to_string(index=False))

print("\n" + "=" * 60)
print("【第2步】预测CLV（简化模型）")
df['predicted_lifetime_months'] = 12
df['CLV'] = df['avg_order_value'] * df['purchase_frequency'] * df['predicted_lifetime_months']
df['CLV'] = df['CLV'].round(2)
print(df[['user_name', 'avg_order_value', 'purchase_frequency', 'CLV']].to_string(index=False))

print("\n" + "=" * 60)
print("【第3步】客户CLV分层")
def classify_clv(clv):
    if clv >= 10000:
        return "高价值客户"
    elif clv >= 5000:
        return "中等价值客户"
    else:
        return "低价值客户"

df['clv_tier'] = df['CLV'].apply(classify_clv)
tier_stats = df.groupby('clv_tier').agg({'user_id': 'count', 'CLV': 'sum'}).rename(columns={'user_id': 'count'})
print(tier_stats.to_string())

print("\n" + "=" * 60)
print("【第4步】高价值客户识别")
high_value = df.nlargest(3, 'CLV')[['user_name', 'CLV', 'clv_tier']]
print(high_value.to_string(index=False))
print(f"\n总CLV预测值: {df['CLV'].sum():.2f} 元")

CLV分析技巧

CLV公式 - 平均订单价值 × 购买频率 × 生命周期
平均订单价值 - 总消费 / 订单数
购买频率 - 订单数 / 时间（月）
生命周期 - 从首次到最近的月数
分层阈值 - 可根据业务调整
