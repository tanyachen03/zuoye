项目2：门店销售对比分析

初级
预计时长：35分钟
技术栈：Python + Pandas + Matplotlib
数据量：72条记录

项目背景

某连锁零售企业在全国6个大区开展业务，管理层希望对比各区域的销售表现，为资源分配和市场策略提供数据支持。

区域销售数据

区域月份销售额(万元)

学习内容

概念讲解
对比分析是商务决策中最常用的方法，通过横向比较不同维度的数据，发现差异、识别优势、定位问题。
小贴士
柱状图适合类别对比，折线图适合趋势展示，两者结合更直观。
常见错误
用饼图展示超过5个类别的数据会让图表难以阅读！建议使用柱状图代替。

代码示例1：按区域汇总销售额

使用 groupby() 按区域汇总销售额：

import pandas as pd

# 按区域汇总销售额
region_sales = df.groupby('区域')['销售额'].sum()
print(region_sales.sort_values(ascending=False))

代码示例2：绘制分组柱状图

使用 Matplotlib 绘制分组柱状图，设置颜色、标题、数据标签：

import matplotlib.pyplot as plt

# 设置中文字体
plt.rcParams['font.sans-serif'] = ['SimHei']

# 绘制柱状图
colors = ['#1e40af', '#3b82f6', '#06b6d4', '#10b981', '#f59e0b', '#ef4444']
plt.figure(figsize=(10, 6))
bars = plt.bar(region_sales.index, region_sales.values, color=colors)

# 添加数据标签
for bar in bars:
    height = bar.get_height()
    plt.text(bar.get_x() + bar.get_width()/2., height,
             f'{height:.0f}万', ha='center', va='bottom')

plt.title('各区域年度销售额对比', fontsize=14)
plt.xlabel('区域', fontsize=12)
plt.ylabel('销售额(万元)', fontsize=12)
plt.show()

代码示例3：计算同比增长率

计算同比增长率，绘制双轴图：

# 计算各区域同比增长率
sales_2023 = df[df['年份']==2023].groupby('区域')['销售额'].sum()
sales_2024 = df[df['年份']==2024].groupby('区域')['销售额'].sum()
growth_rate = (sales_2024 - sales_2023) / sales_2023 * 100

# 绘制双轴图
fig, ax1 = plt.subplots(figsize=(10, 6))
ax2 = ax1.twinx()

ax1.bar(region_sales.index, sales_2024.values, color='#3b82f6', alpha=0.7, label='2024销售额')
ax2.plot(region_sales.index, growth_rate.values, color='#ef4444', marker='o', linewidth=2, label='同比增长率%')

ax1.set_ylabel('销售额(万元)', color='#3b82f6')
ax2.set_ylabel('同比增长率(%)', color='#ef4444')
plt.title('各区域销售额与同比增长率')
plt.show()
