规则词典情感分析原理
通过匹配评论中的情感关键词，计算情感得分来判断整体情感倾向：
  • 正面词匹配：评论中出现"好"、"棒"、"喜欢"等词，加分
  • 负面词匹配：评论中出现"差"、"烂"、"失望"等词，减分
  • 否定词处理："不好"应被判为负面
  • 程度副词加权："非常好"比"好"情感更强

小贴士

常见错误

代码示例：构建情感分数计算函数

# 定义情感词典
positive_words = ["好", "棒", "完美", "喜欢", "推荐", "性价比高", "物流快", ...]
negative_words = ["差", "烂", "失望", "退货", "慢", "破损", "贵", ...]
negations = ["不", "没", "无", "非", "别"]
intensifiers = ["非常", "特别", "极其", "十分", "超"]

def calculate_sentiment(text):
    score = 0
    words = list(text)
    
    for i, word in enumerate(words):
        if word in positive_words:
            if i > 0 and words[i-1] in negations:
                score -= 1  # 否定词反转
            elif i > 0 and words[i-1] in intensifiers:
                score += 2  # 程度副词加强
            else:
                score += 1
        
        if word in negative_words:
            if i > 0 and words[i-1] in negations:
                score += 1  # 否定词反转
            elif i > 0 and words[i-1] in intensifiers:
                score -= 2  # 程度副词加强
            else:
                score -= 1
    
    return "正面" if score > 0 else "负面" if score < 0 else "中性"

# 分析评论
for review in reviews:
    sentiment = calculate_sentiment(review["text"])
    print(f"{review['text']} -> {sentiment}")

# 第1步：定义情感词典
positive_words = ["好", "棒", "完美", "喜欢", "推荐", "高", "快", "清晰", "满意", 
                  "强", "不错", "舒服", "方便", "漂亮", "精细", "值得", "超值", "赞"]
negative_words = ["差", "烂", "失望", "退货", "慢", "破损", "贵", "一般", "麻烦",
                  "不好", "问题", "卡顿", "恶劣", "亏", "垃圾", "坏"]
negations = ["不", "没", "无", "非", "别", "未"]
intensifiers = ["非常", "特别", "十分", "超", "极其", "太"]

# 第2步：情感分数计算函数
def calculate_sentiment(text):
    score = 0
    words = list(text)
    
    for i, word in enumerate(words):
        if word in positive_words:
            if i > 0 and any(neg in text[max(0, text.find(word)-2):text.find(word)] for neg in negations):
                score -= 1
            elif any(word in text and intens in text[max(0, text.find(word)-3):text.find(word)+1] 
                     for intens in intensifiers):
                score += 2
            else:
                score += 1
        
        if word in negative_words:
            if i > 0 and any(neg in text[max(0, text.find(word)-2):text.find(word)] for neg in negations):
                score += 1
            else:
                score -= 1
    
    return "正面" if score > 0 else "负面" if score < 0 else "中性"

分析技巧

词典匹配 - 遍历文本查找情感词
否定反转 - "不"+"好"=负面
程度加权 - "非常"加分翻倍
分数阈值 - >0正面，<0负面，=0中性
高频词统计 - 找出问题焦点
