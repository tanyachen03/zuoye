项目背景

情感分析是NLP（自然语言处理）的重要应用场景，通过分析用户评论的情感倾向，企业可以了解用户对产品或服务的态度，及时发现问题并改进。

  • 正面评论：表达满意、喜欢、推荐等积极情感
  • 负面评论：表达不满、抱怨、失望等消极情感
  • 中性评论：客观描述，不带明显情感倾向

本项目使用基于关键词规则的简单情感分析方法。

# 商品评论数据
reviews = [
    {"id": "R001", "user": "用户A", "product": "手机", "text": "手机很好用，运行流畅，拍照清晰"},
    {"id": "R002", "user": "用户B", "product": "手机", "text": "屏幕太小了，电池也不耐用"},
    {"id": "R003", "user": "用户C", "product": "电脑", "text": "电脑配置不错，性价比高"},
    {"id": "R004", "user": "用户D", "product": "耳机", "text": "音质一般，降噪效果不好"},
    {"id": "R005", "user": "用户E", "product": "平板", "text": "屏幕大，看剧很舒服，推荐购买"},
]

# 【第1步】定义情感关键词
positive_words = ["好", "棒", "满意", "喜欢", "推荐", "不错", "清晰", "流畅", "舒服", "高", "大", "清晰"]
negative_words = ["差", "烂", "失望", "后悔", "小", "不", "不好", "一般", "慢", "贵", "噪音", "坏"]

def analyze_sentiment(text):
    text_lower = text
    pos_count = sum(1 for word in positive_words if word in text_lower)
    neg_count = sum(1 for word in negative_words if word in text_lower)
    
    if pos_count > neg_count:
        return "正面", pos_count, neg_count
    elif neg_count > pos_count:
        return "负面", pos_count, neg_count
    else:
        return "中性", pos_count, neg_count

print("=" * 60)
print("【第2步】情感分析结果")
print("-" * 60)
results = []
for review in reviews:
    sentiment, pos, neg = analyze_sentiment(review["text"])
    results.append(sentiment)
    print(f"[{sentiment:4s}] {review['user']}: {review['text']}")
    print(f"          正面词:{pos} 负面词:{neg}")
    print()

print("=" * 60)
print("【第3步】情感统计")
positive_count = results.count("正面")
negative_count = results.count("负面")
neutral_count = results.count("中性")
total = len(results)

print(f"正面评论: {positive_count} ({positive_count/total*100:.1f}%)")
print(f"负面评论: {negative_count} ({negative_count/total*100:.1f}%)")
print(f"中性评论: {neutral_count} ({neutral_count/total*100:.1f}%)")
print(f"\n总评论数: {total}")
print(f"好评率: {positive_count/total*100:.1f}%")

情感分析技巧

关键词匹配 - 统计正/负面词出现次数
情感得分 = 正面词数 - 负面词数
阈值判断 - 根据得分判断情感倾向
否定词处理 - 考虑"不"等否定词
扩展词库 - 增加更多关键词提高准确率
