项目4：RFM用户分层

数据量：100条交易记录

项目背景

RFM模型是客户价值管理中经典的客户细分方法，通过三个维度对客户进行评估：

  • R（Recency）：最近一次购买距今时间，距离越短价值越高
  • F（Frequency）：购买频率，频率越高价值越高
  • M（Monetary）：累计消费金额，金额越高价值越高

本项目需要根据用户历史交易数据，计算RFM指标并进行用户分层。

用户交易数据

订单ID用户ID用户名购买日期订单金额

分析任务

请完成以下RFM分析：

  • 以分析日期为基准，计算每个用户的R、F、M值
  • 对R、F、M分别进行打分（1-5分）
  • 根据RFM组合，将用户分为8个等级
  • 统计各等级用户数量和消费占比
  • 针对不同层级用户提出运营建议

import pandas as pd
from datetime import datetime

# 用户交易数据
data = [
    {"order_id": "O001", "user_id": "U001", "user_name": "张三", "date": "2024-04-01", "amount": 2999},
    {"order_id": "O002", "user_id": "U002", "user_name": "李四", "date": "2024-03-15", "amount": 1599},
    {"order_id": "O003", "user_id": "U001", "user_name": "张三", "date": "2024-03-20", "amount": 899},
    {"order_id": "O004", "user_id": "U003", "user_name": "王五", "date": "2024-01-10", "amount": 4599},
    {"order_id": "O005", "user_id": "U001", "user_name": "张三", "date": "2024-02-28", "amount": 599},
    {"order_id": "O006", "user_id": "U002", "user_name": "李四", "date": "2024-04-10", "amount": 799},
    {"order_id": "O007", "user_id": "U004", "user_name": "赵六", "date": "2024-04-12", "amount": 1999},
]

df = pd.DataFrame(data)
df['date'] = pd.to_datetime(df['date'])
analysis_date = datetime(2024, 4, 15)

print("=" * 60)
print("【第1步】计算每个用户的R、F、M值")
rfm = df.groupby('user_id').agg({
    'date': lambda x: (analysis_date - x.max()).days,
    'order_id': 'count',
    'amount': 'sum'
}).reset_index()
rfm.columns = ['user_id', 'R', 'F', 'M']
print(rfm.to_string(index=False))

print("\n" + "=" * 60)
print("【第2步】RFM打分（分数越高越好）")
rfm['R_score'] = pd.cut(rfm['R'], bins=[0, 30, 60, 90, 180, 999], labels=[5, 4, 3, 2, 1])
rfm['F_score'] = pd.cut(rfm['F'], bins=[0, 1, 2, 3, 10], labels=[1, 2, 3, 5])
rfm['M_score'] = pd.cut(rfm['M'], bins=[0, 1000, 2000, 4000, 99999], labels=[1, 2, 4, 5])
print(rfm[['user_id', 'R_score', 'F_score', 'M_score']].to_string(index=False))

print("\n" + "=" * 60)
print("【第3步】用户分层")
def segment_user(row):
    r, f, m = int(row['R_score']), int(row['F_score']), int(row['M_score'])
    if r >= 4 and f >= 4 and m >= 4:
        return "重要价值用户"
    elif r >= 4 and f >= 4:
        return "重要保持用户"
    elif r >= 4 and m >= 4:
        return "重要发展用户"
    elif f >= 4 and m >= 4:
        return "重要挽留用户"
    elif r >= 3:
        return "一般价值用户"
    elif f >= 3:
        return "一般发展用户"
    elif m >= 3:
        return "一般挽留用户"
    else:
        return "潜在用户"

rfm['segment'] = rfm.apply(segment_user, axis=1)
print(rfm[['user_id', 'segment']].to_string(index=False))

print("\n" + "=" * 60)
print("【第4步】各层级用户统计")
segment_stats = rfm.groupby('segment').agg({
    'user_id': 'count',
    'M': 'sum'
}).rename(columns={'user_id': 'count', 'M': 'total_amount'})
print(segment_stats.to_string())
