项目4：RFM用户分层模型

中级
预计时长：50分钟
技术栈：Python + Pandas

项目背景

RFM模型是客户价值管理中最经典的用户分层方法，广泛应用于电商、零售、会员运营等领域。

RFM数据预览

用户ID用户名最近购买日期购买次数累计消费(元)

* 时间参考点：2024-12-31

学习内容

概念讲解
R
Recency
最近一次消费
F
Frequency
消费频率
M
Monetary
消费金额

打分规则详解

每个维度分为1-5分，分数越高表示价值越高：

R（最近购买天数）F（购买次数）M（累计金额）
≤30天5分 ≥10次5分 ≥10000元5分
31-60天4分 6-9次4分 5000-9999元4分
61-90天3分 3-5次3分 2000-4999元3分
91-180天2分 2次2分 1000-1999元2分
>180天1分 1次1分 <1000元1分
用户分层对照表

根据RFM三个维度组合，可将用户分为8类：

555 重要价值客户
551 重要保持客户
515 重要发展客户
511 重要挽回客户
155 一般价值客户
151 一般保持客户
115 一般发展客户
111 流失客户
小贴士
RFM三个维度权重可根据行业调整：快消品重F（消费频率），奢侈品重M（消费金额）。
常见错误
R值计算时记得用同一个参考日期！不能各算各的，否则会导致分层结果不准确。

完整实现打分→分层代码

import pandas as pd
from datetime import datetime

# 参考日期
analysis_date = datetime(2024, 12, 31)

# 计算RFM值
rfm = df.groupby('user_id').agg({
    'date': lambda x: (analysis_date - x.max()).days,  # R:最近天数
    'order_id': 'count',  # F:购买次数
    'amount': 'sum'  # M:累计金额
}).reset_index()
rfm.columns = ['user_id', 'R', 'F', 'M']

# RFM打分
def score_r(x, thresholds, labels):
    return pd.cut(x, bins=[-1] + thresholds, labels=labels)

rfm['R_score'] = score_r(rfm['R'], [30, 60, 90, 180], [5,4,3,2,1])
rfm['F_score'] = score_r(rfm['F'], [2, 3, 6, 10], [1,2,3,4,5])
rfm['M_score'] = score_r(rfm['M'], [1000, 2000, 5000, 10000], [1,2,3,4,5])

# 用户分层
def segment_user(row):
    r, f, m = int(row['R_score']), int(row['F_score']), int(row['M_score'])
    if r == 5 and f == 5 and m == 5: return '重要价值客户'
    if r >= 4 and f >= 4 and m >= 4: return '重要客户'
    if r <= 2 and f >= 3 and m >= 3: return '重要挽回客户'
    return '普通客户'

rfm['segment'] = rfm.apply(segment_user, axis=1)
