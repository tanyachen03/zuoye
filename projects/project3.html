项目3：用户复购率分析

中级
预计时长：45分钟

项目背景

复购率是衡量用户粘性和产品价值的核心指标。本项目基于某电商平台6个月的订单数据，分析用户复购行为，识别高价值用户群体。

订单数据预览

订单ID用户ID购买日期商品类别订单金额

* 数据集包含100个用户、500条订单记录，时间跨度6个月

学习内容

概念讲解
复购率 = 重复购买用户数 / 总购买用户数，是衡量用户粘性的核心指标。复购率越高，说明用户对产品/服务的满意度越高，用户生命周期价值越大。
应用场景
电商：分析用户重复购买行为，优化会员体系
订阅服务：跟踪续费率，预测收入
餐饮连锁：分析会员复购，精准营销
小贴士
区分"复购率"和"回购率"：复购是对同一商品的重复购买，回购是再次购买该品牌任意商品。
常见错误
只统计总体复购率而忽略按时间窗口分层（30天/90天/180天）！不同时间窗口的复购率反映不同的用户行为特征。

代码示例3：计算30天、90天复购率

按时间窗口计算复购率：

from datetime import datetime, timedelta

# 转换日期列
df['date'] = pd.to_datetime(df['date'])

# 计算每个用户的首次购买日期
first_purchase = df.groupby('user_id')['date'].min().reset_index()
first_purchase.columns = ['user_id', 'first_date']

# 合并首次购买日期
df = df.merge(first_purchase, on='user_id')

# 计算30天复购率
def calc_repeat_rate(df, days):
    cutoff_date = df['first_date'] + timedelta(days=days)
    repeat_users = df[df['date'] <= cutoff_date].groupby('user_id').size()
    repeat_users = repeat_users[repeat_users >= 2]
    total_users = df['user_id'].nunique()
    return len(repeat_users) / total_users * 100

print(f"30天复购率: {calc_repeat_rate(df, 30):.1f}%")
print(f"90天复购率: {calc_repeat_rate(df, 90):.1f}%")

import pandas as pd
import random

# 模拟生成100个用户、500条订单数据
random.seed(42)
categories = ['电子产品', '服装', '家居', '食品', '美妆']

# 生成用户购买数据
data = []
order_id = 1
for user_id in range(1, 101):
    num_purchases = random.choices(
        [1, 2, 3, 4, 5, 6, 7, 8, 10, 12, 15],
        weights=[30, 25, 15, 10, 8, 5, 3, 2, 1, 0.5, 0.5]
    )[0]
    
    for _ in range(num_purchases):
        month = random.randint(1, 6)
        day = random.randint(1, 28)
        data.append({
            "order_id": f"ORD{order_id:04d}",
            "user_id": f"U{user_id:03d}",
            "date": f"2024-{month:02d}-{day:02d}",
            "category": random.choice(categories),
            "amount": random.randint(50, 3000)
        })
        order_id += 1

df = pd.DataFrame(data)

print("=" * 70)
print(f"【数据概览】总订单数: {len(df)}，总用户数: {df['user_id'].nunique()}")

# 第1步：计算每个用户的购买次数
print("\n" + "=" * 70)
print("【第1步】计算每个用户的购买次数")
user_purchase = df.groupby('user_id').agg({
    'order_id': 'count',
    'amount': 'sum'
}).reset_index()
user_purchase.columns = ['user_id', 'purchase_count', 'total_amount']
print(f"\n购买次数分布：")
print(user_purchase['purchase_count'].value_counts().sort_index().head(10))

# 第2步：计算购买≥3次的用户占比
print("\n" + "=" * 70)
print("【第2步】计算超级用户占比")
total_users = len(user_purchase)
super_users = user_purchase[user_purchase['purchase_count'] >= 3]
super_user_count = len(super_users)
super_user_ratio = super_user_count / total_users * 100

print(f"\n总用户数: {total_users}")
print(f"超级用户数（购买≥3次）: {super_user_count}")
print(f"超级用户占比: {super_user_ratio:.1f}%")

# 第3步：筛选出超级用户
print("\n" + "=" * 70)
print("【第3步】超级用户名单（按购买次数排序）")
super_users_sorted = super_users.sort_values('purchase_count', ascending=False)
print("\nTOP 20 超级用户：")
print(super_users_sorted.head(20).to_string(index=False))

# 第4步：超级用户价值分析
print("\n" + "=" * 70)
print("【第4步】超级用户价值分析")
total_revenue = df['amount'].sum()
super_revenue = super_users['total_amount'].sum()
super_revenue_ratio = super_revenue / total_revenue * 100

print(f"\n总销售额: {total_revenue:,} 元")
print(f"超级用户贡献销售额: {super_revenue:,} 元")
print(f"超级用户贡献占比: {super_revenue_ratio:.1f}%")
print(f"\n结论: {super_user_count}位超级用户（{super_user_ratio:.1f}%）贡献了{super_revenue_ratio:.1f}%的销售额！")

# 可视化：购买次数分布
print("\n" + "=" * 70)
print("【可视化】购买次数分布图")
print("\n用户购买次数分布：")
purchase_dist = user_purchase['purchase_count'].value_counts().sort_index()
max_count = purchase_dist.max()
for count, users in purchase_dist.items():
    bar_len = int(users / max_count * 30)
    bar = "█" * bar_len
    print(f"{count:2d}次: {bar} ({users}人)")

分析技巧

groupby().count() - 统计分组数量
value_counts() - 统计值分布
nunique() - 统计唯一值数量
agg() - 多列聚合计算
sort_values() - 排序
