项目背景

销售预测是企业制定生产计划、采购策略、营销预算的重要依据。时间序列预测通过分析历史数据的变化规律，预测未来的销售趋势。

本项目使用移动平均法进行销售预测，这是一种经典的时间序列预测方法。

学习内容

移动平均法核心公式
SMA(n) = (X₁ + X₂ + ... + Xₙ) / n
简单移动平均：最近n期数据的算术平均值
WMA = w₁×X₁ + w₂×X₂ + ... + wₙ×Xₙ
加权移动平均：近期数据权重更大，权重之和为1
时间序列三大组件

趋势(Trend)

长期上升或下降走势

季节性(Seasonal)

固定周期内的波动

残差(Residual)

随机波动或异常值

小贴士
移动平均的窗口选择很重要：窗口太小噪声多，窗口太大会错过转折点。通常3-6个月适合短期预测，12个月适合捕捉年度趋势。
常见错误
用简单移动平均预测存在趋势的数据，会系统性低估！有趋势的数据应该用加权移动平均或趋势调整。

代码示例1：计算3个月、6个月移动平均

import pandas as pd

# 计算移动平均
df['MA3'] = df['销售额'].rolling(window=3).mean().round(2)
df['MA6'] = df['销售额'].rolling(window=6).mean().round(2)

# 显示结果
print(df[['月份', '销售额', 'MA3', 'MA6']])

代码示例3：用最后3个月平均值预测下月，计算MAPE误差

# 用最后3个月平均预测下月
last_3_months = df['销售额'].tail(3).mean()
forecast_next = last_3_months

# 假设第25个月真实值（用于验证）
actual_next = 280
mape = abs(actual_next - forecast_next) / actual_next * 100

print(f"预测值: {forecast_next:.2f} 万元")
print(f"实际值: {actual_next} 万元")
print(f"MAPE误差: {mape:.2f}%")
