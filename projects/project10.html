项目10：销售趋势预测

高级
预计时长：45分钟
技术栈：Python + Pandas
数据量：12个月数据

项目背景

销售预测是企业制定生产计划、采购策略、营销预算的重要依据。准确的预测可以帮助企业避免库存积压或缺货，提高运营效率。

  • 简单移动平均法(SMA)：用最近n期数据的平均值作为预测值
  • 加权移动平均法(WMA)：给近期数据更高权重
  • 趋势分析法：分析数据变化趋势进行预测

本项目使用简单移动平均法预测下月销售额。

import pandas as pd

# 历史月度销售数据
data = {
    "月份": ["2024-01", "2024-02", "2024-03", "2024-04", "2024-05", "2024-06", "2024-07", "2024-08", "2024-09", "2024-10", "2024-11", "2024-12"],
    "销售额": [120, 135, 142, 158, 165, 180, 175, 190, 205, 198, 220, 235]
}

df = pd.DataFrame(data)

print("=" * 60)
print("【第1步】历史销售数据")
print(df.to_string(index=False))

print("\n" + "=" * 60)
print("【第2步】计算环比增长率")
df['环比增长率'] = df['销售额'].pct_change() * 100
df['环比增长率'] = df['环比增长率'].round(2).fillna(0)
print(df[['月份', '销售额', '环比增长率']].to_string(index=False))
print(f"\n平均增长率: {df['环比增长率'].mean():.2f}%")

print("\n" + "=" * 60)
print("【第3步】3个月移动平均预测")
df['MA3'] = df['销售额'].rolling(window=3).mean().round(2)
df['MA3预测'] = df['MA3'].shift(1)
print(df[['月份', '销售额', 'MA3', 'MA3预测']].to_string(index=False))

ma3_forecast = df['MA3'].iloc[-1]
print(f"\n3个月MA预测下月销售额: {ma3_forecast:.2f} 万元")

print("\n" + "=" * 60)
print("【第4步】6个月移动平均预测")
df['MA6'] = df['销售额'].rolling(window=6).mean().round(2)
print(df[['月份', '销售额', 'MA6']].to_string(index=False))

ma6_forecast = df['MA6'].iloc[-1]
print(f"\n6个月MA预测下月销售额: {ma6_forecast:.2f} 万元")

print("\n" + "=" * 60)
print("【第5步】预测结果对比")
print(f"\n3个月MA预测: {ma3_forecast:.2f} 万元")
print(f"6个月MA预测: {ma6_forecast:.2f} 万元")
print(f"\n综合预测 (两者平均): {(ma3_forecast + ma6_forecast)/2:.2f} 万元")

print("\n" + "=" * 60)
print("【第6步】销售趋势可视化（ASCII版）")
print("\n销售趋势图：")
max_sales = df['销售额'].max()
for idx, row in df.iterrows():
    bar_length = int(row['销售额'] / max_sales * 40)
    bar = "█" * bar_length
    print(f"{row['月份']} | {bar} {row['销售额']}万")

print("\n预测趋势：")
forecast_value = (ma3_forecast + ma6_forecast) / 2
bar_length = int(forecast_value / max_sales * 40)
bar = "░" * bar_length
print(f"2025-01 | {bar} {forecast_value:.2f}万 (预测)")

预测分析技巧

rolling() - 计算移动平均
pct_change() - 计算环比变化率
MA3 - 近3期平均值
MA6 - 近6期平均值
窗口选择 - 数据稳定用长窗口，变化快用短窗口
