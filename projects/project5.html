学习内容

核心概念
项集 (Itemset)：一个或多个商品的集合
例如：{iPhone 15, AirPods} 表示同时购买这两个商品的组合
支持度 (Support)：某商品组合在所有交易中出现的频率
Support(A→B) = P(A∩B) = count(A,B) / 总交易数
置信度 (Confidence)：购买A商品的用户中，同时购买B商品的比率
Confidence(A→B) = P(B|A) = Support(A,B) / Support(A)
提升度 (Lift)：关联规则的实际效果与随机情况的比例
Lift(A→B) = Confidence(A→B) / Support(B)
Lift > 1 表示正相关，Lift < 1 表示负相关，Lift = 1 表示无关联

小贴士
Apriori算法的关键在于利用先验性质剪枝：如果一个项集是频繁的，那么它的所有子集也必须是频繁的。
常见错误
支持度阈值设置过高会导致找不到有用的关联！建议从较低值（如0.01-0.05）开始尝试。

代码示例：使用mlxtend实现Apriori算法

# 数据格式转换：将交易数据转换为列表格式
basket = df.groupby('InvoiceNo')['Description'].apply(list).tolist()

# 调用Apriori算法挖掘频繁项集
from mlxtend.frequent_patterns import apriori, association_rules

# 找出支持度 >= 3% 的频繁项集
frequent_itemsets = apriori(basket, min_support=0.03, use_colnames=True)

# 计算关联规则，筛选置信度 > 0.5 的规则
rules = association_rules(frequent_itemsets, metric="confidence", min_threshold=0.5)
rules = rules.sort_values('confidence', ascending=False)

]

df = pd.DataFrame(data)

# 第1步：转换为交易列表
transactions = df.groupby('InvoiceNo')['Description'].apply(list).tolist()
n_transactions = len(transactions)
print("=" * 70)
print(f"【第1步】交易列表转换（共{n_transactions}笔交易）")
for i, t in enumerate(transactions):
    print(f"  {i+1}: {t}")

# 第2步：计算商品支持度
all_items = [item for trans in transactions for item in trans]
item_counts = Counter(all_items)
total_items = len(transactions)

print("
" + "=" * 70)
print("【第2步】各商品支持度")
item_supports = {}
for item, count in item_counts.most_common():
    support = count / total_items
    item_supports[item] = support
    print(f"  {item}: {count}次, 支持度={support:.2%}")

# 第3步：计算二项商品组合
pair_counts = Counter()
for trans in transactions:
    for pair in combinations(sorted(set(trans)), 2):
        pair_counts[pair] += 1

print("
" + "=" * 70)
print("【第3步】二项商品组合分析")
pair_supports = {}
for pair, count in pair_counts.most_common():
    support = count / total_items
    pair_supports[pair] = support
    if support >= 0.03:
        print(f"  {pair[0]} + {pair[1]}: {count}次, 支持度={support:.2%}")

# 第4步：关联规则
print("
" + "=" * 70)
print("【第4步】关联规则（置信度 > 0.5）")
rules = []
for pair, count in pair_counts.items():
    item_a, item_b = pair
    support_ab = count / total_items
    support_a = item_supports[item_a]
    support_b = item_supports[item_b]
    confidence = support_ab / support_a if support_a > 0 else 0
    lift = confidence / support_b if support_b > 0 else 0
    
    if support_ab >= 0.03 and confidence > 0.5:
        rules.append({
            'antecedents': item_a,
            'consequents': item_b,
            'support': support_ab,
            'confidence': confidence,
            'lift': lift
        })

# 按置信度降序
rules = sorted(rules, key=lambda x: x['confidence'], reverse=True)

if rules:
    print(f"
找到 {len(rules)} 条有效规则：")
    print("-" * 70)
    print(f"{'前项':<15} {'后项':<15} {'支持度':<10} {'置信度':<10} {'提升度':<10}")
    print("-" * 70)
    for r in rules:
        print(f"{r['antecedents']:<15} {r['consequents']:<15} {r['support']:.2%}     {r['confidence']:.2%}     {r['lift']:.2f}")
else:
    print("没有找到符合条件的关联规则，尝试降低阈值")

print("
" + "=" * 70)
print("【结论分析】")
print("提升度Lift > 1 表示正相关，说明这两个商品有关联购买倾向")
