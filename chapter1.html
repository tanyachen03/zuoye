Python环境搭建

课程：Python编程基础

Python语言介绍

Python是一门简洁易学的高级编程语言，广泛应用于数据分析、人工智能、Web开发等领域。它拥有丰富的第三方库，是数据分析师必备的工具。

安装Python环境

从Python官网下载安装包，选择3.x最新版本。Windows用户安装时请勾选"Add Python to PATH"选项。安装完成后在终端输入 python --version 验证。

配置开发工具

推荐使用VS Code或PyCharm作为Python开发工具。安装后配置Python解释器路径，安装Python扩展插件以获得代码补全、语法高亮等功能。

第一个Python程序

打开文本编辑器，输入 print("Hello, Python!")，保存为 hello.py。在终端运行 python hello.py，你将看到输出信息。

包管理器pip

pip是Python的包管理工具。使用 pip install package_name 安装第三方库，如 pip install pandas。使用 pip list 查看已安装的包。

💡 要点总结

本章介绍了Python环境搭建的核心知识点，包括Python语言介绍、安装Python环境等关键内容。通过系统学习，你将掌握相关概念和方法。

✏️ 学习小贴士

建议在学习时结合实际代码练习，理论结合实践是掌握数据分析技能的最佳方式。遇到问题时多查文档、多动手实验，培养独立解决问题的能力。

⚠️ 注意事项

学习过程中遇到问题不要气馁，数据分析是实践性很强的技能，需要持续练习和积累。从错误中学习是成长的重要途径。

📝 课后习题

习题 1
以下哪个命令用于检查Python版本？
  • A. python --check
  • B. python --version
  • C. python -v
  • D. python --info
正确答案：B
解析：python --version 或 python -V 是查看Python版本的标准命令。
习题 2
pip install numpy 命令的作用是？
  • A. 卸载numpy
  • B. 更新numpy
  • C. 安装numpy
  • D. 查看numpy
正确答案：C
解析：pip install 命令用于安装第三方Python包。
习题 3
Python代码文件的扩展名是？
  • A. .pt
  • B. .py
  • C. .python
  • D. .txt
正确答案：B
解析：Python代码文件使用 .py 作为标准扩展名。
习题 4
推荐用于Python开发的工具不包括？
  • A. VS Code
  • B. PyCharm
  • C. 记事本
  • D. Jupyter
正确答案：C
解析：记事本没有代码高亮和调试功能，不适合专业开发。推荐使用VS Code、PyCharm或Jupyter。
习题 5
执行Python脚本的命令是？
  • A. python script.py
  • B. run script.py
  • C. execute script.py
  • D. ./script.py run
正确答案：A
解析：python filename.py 是执行Python脚本的标准方式。

💻 动手实践

实践 1
安装并验证Python环境 [初级]
  1. 在你的电脑上安装Python 3.x最新版本
  2. 打开终端/命令行，输入 python --version 和 pip --version
  3. 确认两者都能正常显示版本信息
  4. 将输出结果记录下来
实践 2
编写并运行Hello World程序 [初级]
  1. 创建一个名为 hello.py 的文件
  2. 写入打印"Hello, 数析学院！"的代码
  3. 通过命令行运行该脚本，确认输出正确
  4. 尝试修改打印的内容并重新运行
实践 3
使用pip安装一个数据分析包 [中级]
  1. 使用 pip install pandas 安装Pandas库
  2. 安装完成后运行 pip list 确认安装成功
  3. 启动Python交互模式（输入 python）
  4. 输入 import pandas as pd 测试是否能正常导入
