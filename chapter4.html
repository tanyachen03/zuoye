一、用户画像概述

用户画像定义

用户画像是根据用户的属性、行为和偏好等信息构建的用户虚拟代表，是一种描述用户特征的方法。通过用户画像，企业可以更好地了解用户需求，提供个性化服务。

人口属性
消费行为
兴趣偏好
地理位置
用户画像维度

静态属性

年龄、性别、地域、职业

动态行为

浏览、购买、收藏、分享

心理特征

兴趣爱好、消费观念

社交关系

社交网络、影响力

知识点测验

以下哪个不是用户画像的常见维度？

人口属性
企业规模
兴趣偏好
地理位置

解析：用户画像的常见维度包括人口属性、消费行为、兴趣偏好和地理位置等，企业规模不是用户画像的常见维度。

二、RFM模型原理

RFM三要素

RFM模型是一种常用的用户价值分析方法，通过三个维度评估用户价值：

  • Recency (最近一次消费)：用户最近一次购买的时间间隔
  • Frequency (消费频率)：用户在一定时间内的购买次数
  • Monetary (消费金额)：用户在一定时间内的消费总额
RFM模型示意图
R
F
M

将三个维度得分相乘或加权求和，得到用户价值总分

知识点测验

RFM模型中的"F"代表什么？

Recency（最近一次消费）
Frequency（消费频率）
Monetary（消费金额）
Future（未来消费）

解析：RFM模型的三个维度分别是Recency（最近一次消费）、Frequency（消费频率）、Monetary（消费金额）。

RFM打分规则

为每个维度设定打分标准，通常采用5分制：

# RFM打分规则示例 import pandas as pd # 定义打分函数 def score_recency(days): if days <= 7: return 5 elif days <= 14: return 4 elif days <= 30: return 3 elif days <= 60: return 2 else: return 1 def score_frequency(count): if count >= 10: return 5 elif count >= 6: return 4 elif count >= 3: return 3 elif count >= 2: return 2 else: return 1 def score_monetary(amount): if amount >= 1000: return 5 elif amount >= 500: return 4 elif amount >= 200: return 3 elif amount >= 100: return 2 else: return 1 # 应用打分 df['R_score'] = df['recency_days'].apply(score_recency) df['F_score'] = df['frequency'].apply(score_frequency) df['M_score'] = df['monetary'].apply(score_monetary) df['RFM_total'] = df['R_score'] + df['F_score'] + df['M_score']

三、用户分层策略

用户价值分层

根据RFM得分，将用户分为不同层级，实施差异化运营策略：

用户分层模型

重要价值用户

R高、F高、M高

重要发展用户

R高、F低、M高

重要保持用户

R低、F高、M高

重要挽留用户

R低、F低、M高

一般价值用户

R高、F高、M低

流失用户

R低、F低、M低

分层运营策略

针对不同层级用户，制定差异化运营策略：

高价值用户：VIP服务、专属优惠
潜力用户：引导复购、提升客单价
沉睡用户：唤醒活动、个性化推荐
流失用户：挽回活动、特殊优惠

提示：用户分层不是一成不变的，需要定期更新。建议每季度重新评估用户层级，及时调整运营策略。

知识点测验

RFM模型中，"R高、F高、M高的用户属于哪类？

重要价值用户
重要发展用户
重要保持用户
重要挽留用户

解析：R高、F高、M高的用户属于重要价值用户。

四、用户分布可视化

用户分层分布

通过可视化展示用户分层结果，直观了解用户结构。

# 用户分层可视化 import pandas as pd import matplotlib.pyplot as plt # 用户分层数据 segment_data = { '用户层级': ['重要价值', '重要发展', '重要保持', '重要挽留', '一般价值', '流失用户'], '用户数量': [1200, 850, 680, 450, 2100, 3200] } df = pd.DataFrame(segment_data) # 计算占比 df['占比(%)'] = (df['用户数量'] / df['用户数量'].sum()) * 100 # 饼图可视化 plt.figure(figsize=(10, 6)) colors = ['#1e40af', '#3b82f6', '#06b6d4', '#f59e0b', '#6b7280', '#9ca3af'] plt.pie(df['用户数量'], labels=df['用户层级'], colors=colors, autopct='%1.1f%%', startangle=90) plt.title('用户分层分布', fontsize=14, fontweight='bold') plt.axis('equal') plt.show()
