NumPy数组基础

NumPy介绍

NumPy(Numerical Python)是Python科学计算的基础包。它提供了高效的多维数组对象ndarray，以及对数组进行快速运算的工具。NumPy数组比Python原生列表更节省内存，运算速度更快，是Pandas、Scikit-learn等库的基础。

导入NumPy

使用import numpy as np导入NumPy库，这是约定俗成的简写方式。导入后就可以使用np前缀调用NumPy的各种功能。首先确保已经安装了NumPy，可以使用pip install numpy或通过Anaconda安装。

创建NumPy数组

最基本的创建方法是使用np.array()函数，将Python列表转换为NumPy数组。例如arr = np.array([1, 2, 3, 4, 5])创建一维数组，np.array([[1,2], [3,4]])创建二维数组。还可以使用np.zeros、np.ones、np.full创建指定形状和值的数组。

数组的属性

ndarray对象有几个重要的属性。shape返回数组的维度，如(3,4)表示3行4列。ndim返回数组的维数。dtype返回数组中元素的数据类型，如int64、float64。size返回数组中元素的总个数。itemsize返回每个元素占用的字节数。

特殊数组创建

NumPy提供了多种创建特殊数组的函数。np.arange(起始, 结束, 步长)类似于Python的range，但返回数组。np.linspace(起始, 结束, 数量)创建等间距的数列。np.random.rand(shape)创建指定形状的随机数组。np.eye(n)创建n×n的单位矩阵。

💡 要点总结
NumPy数组ndarray是NumPy的核心对象。通过np.array从列表创建，或使用zeros、ones、arange、linspace等函数创建。shape、dtype、ndim是数组的重要属性。
📌 小贴士
在数据分析中，经常需要将各种数据转换为NumPy数组进行运算。熟悉数组的创建方法和属性查询是第一步。可以使用print(arr)查看数组内容，使用arr.shape查看数组形状。
⚠️ 注意事项
NumPy数组一旦创建，其数据类型dtype是固定的。如果需要不同类型的数组，需要使用astype()方法进行显式转换，而不能直接修改元素类型。
