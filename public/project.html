📈 电商销售数据分析

分析销售趋势、识别爆款产品、发现客户购买行为模式。

返回项目列表

📋 业务背景

某电商平台近一年的销售数据，包含订单信息、商品信息和客户信息。作为数据分析师，你需要帮助业务团队了解销售情况，发现业务机会。

🎯 分析目标

  • 分析月度销售趋势，识别旺季和淡季
  • 找出销售额最高的Top 10产品
  • 分析不同地区的销售分布
  • 发现客户购买行为模式

💡 小贴士

注意处理缺失值和异常订单，确保数据质量
按月聚合分析趋势更清晰，可以使用 resample 方法
使用分组聚合发现产品规律，groupby 是强大的工具

📝 代码示例

# 导入必要的库
import pandas as pd
import numpy as np

# 读取数据
df = pd.read_csv('sales_data.csv')

# 查看数据结构
print(df.head())
print(df.info())

# 数据清洗
# 1. 处理缺失值
df = df.dropna(subset=['订单金额', '商品ID'])

# 2. 转换日期格式
df['订单日期'] = pd.to_datetime(df['订单日期'])

# 3. 按月份分组统计销售额
monthly_sales = df.groupby(df['订单日期'].dt.month)['订单金额'].sum()

# 4. 找出Top 10产品
top_products = df.groupby('商品ID')['订单金额'].sum().sort_values(ascending=False).head(10)

print('\\n月度销售额:')
print(monthly_sales)

print('\\nTop 10产品:')
print(top_products)
