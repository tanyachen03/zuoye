RFM实战：打分与分层

通过完整代码实战，掌握RFM模型的打分方法与用户分层实现

本节目标

  • 掌握RFM打分的多种方法
  • 学会实现用户分层代码
  • 理解分层结果的业务解读
  • 能够输出RFM分析报告
  • 了解RFM结果的可视化展示

一、RFM打分方法

打分方法概述

RFM打分是将原始指标转换为标准化分值的过程，常用的打分方法包括：

1
分位数法（推荐）
将用户按指标值排序，均分为5档，每档赋值1-5分。R值越小得分越高，F和M值越大得分越高。
2
均值法
以均值为界，高于均值赋高分（如5分），低于均值赋低分（如1分），简单但区分度较低。
3
自定义规则法
根据业务特点自定义打分规则，如R值：7天内5分、7-30天4分、30-90天3分等。

完整RFM打分代码

# ======================================== # RFM完整打分与分层代码 # ======================================== import pandas as pd import numpy as np from datetime import datetime, timedelta # 1. 准备示例数据 # ------------------------------ np.random.seed(42) # 模拟1000个用户的交易数据 n_users = 500 n_orders = 3000 # 生成订单数据 orders = pd.DataFrame({ 'order_id': [f'O{i:06d}' for i in range(n_orders)], 'user_id': np.random.choice([f'U{i:05d}' for i in range(n_users)], n_orders), 'order_date': [ (datetime(2024, 1, 1) + timedelta(days=np.random.randint(0, 365))).strftime('%Y-%m-%d') for _ in range(n_orders) ], 'amount': np.round(np.random.exponential(300, n_orders) + 50, 2) }) orders['order_date'] = pd.to_datetime(orders['order_date']) print("=== 订单数据样例 ===") print(orders.head()) print(f"\n总订单数: {len(orders)}, 总用户数: {orders['user_id'].nunique()}")
# 2. 计算RFM原始值 # ------------------------------ # 设置分析基准日期 analysis_date = datetime(2024, 12, 31) # 按用户聚合计算RFM rfm = orders.groupby('user_id').agg({ 'order_date': lambda x: (analysis_date - x.max()).days, 'order_id': 'nunique', 'amount': 'sum' }).reset_index() rfm.columns = ['user_id', 'R', 'F', 'M'] print("=== RFM原始值 ===") print(rfm.head(10)) print("\n=== RFM统计描述 ===") print(rfm[['R', 'F', 'M']].describe().round(2))
# 3. RFM打分（分位数法） # ------------------------------ # R值打分：R越小越好，所以labels倒序 rfm['R_score'] = pd.qcut(rfm['R'], 5, labels=[5, 4, 3, 2, 1], duplicates='drop').astype('int') # F值打分：F越大越好 rfm['F_score'] = pd.qcut(rfm['F'], 5, labels=[1, 2, 3, 4, 5], duplicates='drop').astype('int') # M值打分：M越大越好 rfm['M_score'] = pd.qcut(rfm['M'], 5, labels=[1, 2, 3, 4, 5], duplicates='drop').astype('int') # 计算RFM总分（加权平均，权重可调整） rfm['RFM_total'] = ( rfm['R_score'] * 0.3 + rfm['F_score'] * 0.3 + rfm['M_score'] * 0.4 ).round(2) print("=== RFM打分结果 ===") print(rfm.head(10)) print("\n=== 各分值分布 ===") print("R分值分布:") print(rfm['R_score'].value_counts().sort_index()) print("\nF分值分布:") print(rfm['F_score'].value_counts().sort_index()) print("\nM分值分布:") print(rfm['M_score'].value_counts().sort_index())
代码输出说明

上述代码完成了RFM打分的核心步骤：1) 从订单数据聚合计算R、F、M原始值；2) 使用分位数法将各维度分为5档并赋值；3) 计算加权总分。注意R值的打分是倒序的，因为R值越小越好。

二、用户分层实现

8类用户分层

根据R、F、M三个维度的高低，可以将用户分为8个层级。我们使用均值作为高低分界线。

# 4. 用户分层 # ------------------------------ # 计算各维度均值 r_mean = rfm['R_score'].mean() f_mean = rfm['F_score'].mean() m_mean = rfm['M_score'].mean() print(f"R均值: {r_mean:.2f}, F均值: {f_mean:.2f}, M均值: {m_mean:.2f}") # 判断高低（高于均值为高，否则为低） rfm['R_level'] = (rfm['R_score'] > r_mean).astype('int') rfm['F_level'] = (rfm['F_score'] > f_mean).astype('int') rfm['M_level'] = (rfm['M_score'] > m_mean).astype('int') # 定义分层函数 def get_segment(row): r, f, m = row['R_level'], row['F_level'], row['M_level'] if r == 1 and f == 1 and m == 1: return '重要价值用户' elif r == 1 and f == 0 and m == 1: return '重要发展用户' elif r == 0 and f == 1 and m == 1: return '重要保持用户' elif r == 0 and f == 0 and m == 1: return '重要挽留用户' elif r == 1 and f == 1 and m == 0: return '一般价值用户' elif r == 1 and f == 0 and m == 0: return '一般发展用户' elif r == 0 and f == 1 and m == 0: return '一般保持用户' else: return '低价值用户' rfm['segment'] = rfm.apply(get_segment, axis=1) # 分层统计 segment_stats = rfm.groupby('segment').agg({ 'user_id': 'count', 'M': 'sum' }).reset_index() segment_stats.columns = ['用户分层', '用户数', '消费总额'] segment_stats['用户占比(%)'] = (segment_stats['用户数'] / segment_stats['用户数'].sum() * 100).round(2) segment_stats['金额占比(%)'] = (segment_stats['消费总额'] / segment_stats['消费总额'].sum() * 100).round(2) segment_stats = segment_stats.sort_values('消费总额', ascending=False) print("\n=== 用户分层统计 ===") print(segment_stats.to_string(index=False))
真实商业案例：某零售企业RFM分层分析

背景：某零售企业拥有50万会员，年销售额10亿，希望通过RFM分析优化会员运营。

分层结果：

  • 重要价值用户（3.2%）：贡献38%销售额，年人均消费7500元
  • 重要保持用户（5.8%）：贡献22%销售额，但存在流失风险
  • 低价值用户（42%）：贡献仅8%销售额，年人均消费380元

运营策略：

  • 重要价值用户：专属客服、生日礼遇、新品优先购
  • 重要保持用户：定向召回活动、会员积分提醒
  • 一般用户：促销推送、品类推荐
  • 低价值用户：自动化营销、成本控制

效果：6个月后，重要保持用户召回率提升30%，整体会员活跃度提升18%。

常见错误：在进行用户分层时，常见以下错误：1) 分层标准过于复杂，难以落地执行；2) 忽视分层结果的动态变化，不定期更新；3) 只看分层结果，不制定针对性策略；4) 分层粒度过细，导致用户分布过于分散。

三、RFM分析报告输出

生成分析报告

完整的RFM分析报告应包含数据概览、分层结果、用户特征分析和运营建议。

# 5. 生成RFM分析报告 # ------------------------------ def generate_rfm_report(rfm_df, segment_stats): """生成RFM分析报告""" report = """ ======================================== RFM用户分层分析报告 ======================================== 一、数据概览 ----------- - 分析用户数: {} - 分析周期: 最近365天 - 基准日期: {} 二、RFM指标统计 --------------- - R值（最近消费天数）: 均值{:.1f}天, 中位数{:.1f}天 - F值（消费频次）: 均值{:.1f}次, 中位数{:.1f}次 - M值（消费金额）: 均值{:.0f}元, 中位数{:.0f}元 三、用户分层结果 ---------------- """.format( len(rfm_df), '2024-12-31', rfm_df['R'].mean(), rfm_df['R'].median(), rfm_df['F'].mean(), rfm_df['F'].median(), rfm_df['M'].mean(), rfm_df['M'].median() ) for _, row in segment_stats.iterrows(): report += "- {}: {}人 ({}%), 消费{:.0f}元 ({}%)\n".format( row['用户分层'], row['用户数'], row['用户占比(%)'], row['消费总额'], row['金额占比(%)'] ) report += """ 四、运营建议 ------------ 1. 重要价值用户：提供VIP专属服务，维持高忠诚度 2. 重要保持用户：主动触达，防止流失 3. 重要发展用户：引导提升消费频次 4. 低价值用户：低成本维护，避免过度投入 ======================================== """ return report # 生成并打印报告 report = generate_rfm_report(rfm, segment_stats) print(report)
# 6. 导出RFM结果到CSV # ------------------------------ # 选择需要导出的列 export_cols = ['user_id', 'R', 'F', 'M', 'R_score', 'F_score', 'M_score', 'RFM_total', 'segment'] rfm_export = rfm[export_cols].copy() rfm_export.columns = ['用户ID', 'R值', 'F值', 'M值', 'R分', 'F分', 'M分', 'RFM总分', '用户分层'] # 导出CSV（实际使用时取消注释） # rfm_export.to_csv('rfm_analysis_result.csv', index=False, encoding='utf-8-sig') print("=== RFM分析结果预览 ===") print(rfm_export.head(15)) print("\n=== 各分层用户样例 ===") for segment in rfm['segment'].unique()[:3]: print(f"\n{segment}:") sample = rfm[rfm['segment'] == segment][['user_id', 'R', 'F', 'M', 'RFM_total']].head(3) print(sample.to_string(index=False))

小贴士：RFM分析结果应该定期更新（建议月度或季度），以跟踪用户分层的变化。可以计算用户的"分层迁移率"，了解用户在不同分层之间的流动情况，这对评估运营效果很有帮助。

知识点测验

在RFM打分中，为什么R值的分值标签是倒序的（5,4,3,2,1）？

因为R值越大越好
因为R值越小越好，最近消费的用户得分应该更高
这是编程错误，应该正序
为了与其他指标区分

解析：R值表示最近一次消费距离现在的天数，R值越小说明用户最近刚消费过，活跃度越高，应该得到更高的分数。因此R值的打分标签是倒序的，R值最小的那部分用户得5分。
