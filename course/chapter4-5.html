本章综合案例

综合运用用户画像、RFM模型和生命周期管理，完成完整的用户分析项目

电商平台用户价值分析项目

某电商平台希望对过去一年的用户进行价值分析，制定差异化的运营策略。本案例将综合运用用户画像、RFM模型和生命周期管理方法，完成完整的用户分析。

用户规模：10万+
分析周期：1年
数据量：50万订单

案例目标

  • 完成用户数据清洗与预处理
  • 构建用户画像标签体系
  • 实现RFM用户分层分析
  • 识别用户生命周期阶段
  • 输出运营策略建议

一、数据准备与预处理

数据概览

首先加载并了解数据的基本情况，包括用户信息表和订单记录表。

# ======================================== # 电商平台用户价值分析 - 完整代码 # ======================================== import pandas as pd import numpy as np from datetime import datetime, timedelta import warnings warnings.filterwarnings('ignore') # 设置随机种子，确保结果可复现 np.random.seed(42) # ======================================== # 1. 数据模拟（实际项目中从数据库读取） # ======================================== # 模拟用户基础数据 n_users = 10000 users = pd.DataFrame({ 'user_id': [f'U{i:06d}' for i in range(n_users)], 'register_date': [ (datetime(2023, 1, 1) + timedelta(days=np.random.randint(0, 365))).strftime('%Y-%m-%d') for _ in range(n_users) ], 'gender': np.random.choice(['男', '女'], n_users, p=[0.45, 0.55]), 'age': np.random.normal(32, 10, n_users).astype('int').clip(18, 60), 'city_level': np.random.choice(['一线', '二线', '三线', '其他'], n_users, p=[0.25, 0.35, 0.25, 0.15]) }) # 模拟订单数据 n_orders = 50000 orders = pd.DataFrame({ 'order_id': [f'O{i:08d}' for i in range(n_orders)], 'user_id': np.random.choice(users['user_id'], n_orders), 'order_date': [ (datetime(2024, 1, 1) + timedelta(days=np.random.randint(0, 365))).strftime('%Y-%m-%d') for _ in range(n_orders) ], 'category': np.random.choice(['数码', '服饰', '美妆', '食品', '家居'], n_orders), 'amount': np.round(np.random.exponential(200, n_orders) + 50, 2), 'quantity': np.random.choice([1, 2, 3, 4, 5], n_orders, p=[0.5, 0.25, 0.15, 0.07, 0.03]) }) # 转换日期格式 orders['order_date'] = pd.to_datetime(orders['order_date']) users['register_date'] = pd.to_datetime(users['register_date']) print("=== 数据概览 ===") print(f"用户数: {len(users)}") print(f"订单数: {len(orders)}") print(f"总销售额: {orders['amount'].sum():,.2f}元") print(f"订单时间范围: {orders['order_date'].min()} ~ {orders['order_date'].max()}")

二、用户画像构建

1 构建用户基础画像标签
# ======================================== # 2. 用户画像构建 # ======================================== # 计算用户消费统计 user_order_stats = orders.groupby('user_id').agg({ 'order_id': 'count', 'amount': ['sum', 'mean'], 'quantity': 'sum', 'order_date': ['min', 'max'] }).reset_index() user_order_stats.columns = ['user_id', 'order_count', 'total_amount', 'avg_amount', 'total_quantity', 'first_order_date', 'last_order_date'] # 合并用户基础信息 user_profile = users.merge(user_order_stats, on='user_id', how='left') # 填充无消费用户 user_profile['order_count'] = user_profile['order_count'].fillna(0).astype('int') user_profile['total_amount'] = user_profile['total_amount'].fillna(0) user_profile['avg_amount'] = user_profile['avg_amount'].fillna(0) user_profile['total_quantity'] = user_profile['total_quantity'].fillna(0).astype('int') # 构建用户标签 # 年龄分段 user_profile['age_group'] = pd.cut(user_profile['age'], bins=[0, 25, 35, 45, 60], labels=['18-25岁', '26-35岁', '36-45岁', '46-60岁']) # 消费能力分层 user_profile['spending_tier'] = pd.cut(user_profile['total_amount', bins=[-1, 0, 500, 2000, 5000, float('inf')], labels=['无消费', '低消费', '中消费', '高消费', '超高消费']) # 活跃度标签 analysis_date = datetime(2024, 12, 31) user_profile['days_since_last_order'] = (analysis_date - user_profile['last_order_date']).dt.days user_profile['days_since_last_order'] = user_profile['days_since_last_order'].fillna(999) user_profile['activity_status'] = user_profile['days_since_last_order'].apply( lambda x: '活跃' if x <= 30 else ('沉默' if x <= 90 else '流失') ) # 计算偏好品类 category_pref = orders.groupby(['user_id', 'category']).size().reset_index(name='count') category_pref = category_pref.loc[category_pref.groupby('user_id')['count'].idxmax()] category_pref = category_pref[['user_id', 'category']].rename(columns={'category': 'favorite_category'}) user_profile = user_profile.merge(category_pref, on='user_id', how='left') print("=== 用户画像统计 ===") print("\n年龄分布:") print(user_profile['age_group'].value_counts()) print("\n消费能力分布:") print(user_profile['spending_tier'].value_counts()) print("\n活跃状态分布:") print(user_profile['activity_status'].value_counts())
用户画像构建完成

已构建包含年龄分段、消费能力、活跃状态、偏好品类等维度的用户画像标签体系，为后续RFM分析奠定基础。

三、RFM用户分层

2 计算RFM指标并进行用户分层
# ======================================== # 3. RFM分析与用户分层 # ======================================== # 筛选有消费的用户 active_users = user_profile[user_profile['order_count'] > 0].copy() # 计算RFM原始值 active_users['R'] = active_users['days_since_last_order'] active_users['F'] = active_users['order_count'] active_users['M'] = active_users['total_amount'] # RFM打分（分位数法） active_users['R_score'] = pd.qcut(active_users['R'], 5, labels=[5, 4, 3, 2, 1], duplicates='drop').astype('int') active_users['F_score'] = pd.qcut(active_users['F'], 5, labels=[1, 2, 3, 4, 5], duplicates='drop').astype('int') active_users['M_score'] = pd.qcut(active_users['M'], 5, labels=[1, 2, 3, 4, 5], duplicates='drop').astype('int') # 计算RFM总分 active_users['RFM_total'] = ( active_users['R_score'] * 0.3 + active_users['F_score'] * 0.3 + active_users['M_score'] * 0.4 ).round(2) # 用户分层 r_mean = active_users['R_score'].mean() f_mean = active_users['F_score'].mean() m_mean = active_users['M_score'].mean() def get_segment(row): r = 1 if row['R_score'] > r_mean else 0 f = 1 if row['F_score'] > f_mean else 0 m = 1 if row['M_score'] > m_mean else 0 if r == 1 and f == 1 and m == 1: return '重要价值用户' elif r == 1 and f == 0 and m == 1: return '重要发展用户' elif r == 0 and f == 1 and m == 1: return '重要保持用户' elif r == 0 and f == 0 and m == 1: return '重要挽留用户' elif r == 1 and f == 1 and m == 0: return '一般价值用户' elif r == 1 and f == 0 and m == 0: return '一般发展用户' elif r == 0 and f == 1 and m == 0: return '一般保持用户' else: return '低价值用户' active_users['segment'] = active_users.apply(get_segment, axis=1) # 分层统计 segment_stats = active_users.groupby('segment').agg({ 'user_id': 'count', 'total_amount': 'sum', 'RFM_total': 'mean' }).reset_index() segment_stats.columns = ['用户分层', '用户数', '消费总额', '平均RFM分'] segment_stats['用户占比%'] = (segment_stats['用户数'] / segment_stats['用户数'].sum() * 100).round(1) segment_stats['金额占比%'] = (segment_stats['消费总额'] / segment_stats['消费总额'].sum() * 100).round(1) segment_stats = segment_stats.sort_values('消费总额', ascending=False) print("=== RFM用户分层结果 ===") print(segment_stats.to_string(index=False))

四、生命周期阶段识别

3 识别用户生命周期阶段
# ======================================== # 4. 生命周期阶段识别 # ======================================== def identify_lifecycle(row): """基于RFM分值识别生命周期阶段""" r, f, m = row['R_score'], row['F_score'], row['M_score'] if r >= 4 and f <= 2 and m <= 2: return '引入期' elif r >= 3 and (f >= 3 or m >= 3) and not (f >= 4 and m >= 4): return '成长期' elif r >= 3 and f >= 4 and m >= 4: return '成熟期' elif r <= 3 and r >= 2 and f >= 2 and m >= 2: return '衰退期' else: return '流失期' active_users['lifecycle_stage'] = active_users.apply(identify_lifecycle, axis=1) # 生命周期阶段统计 lifecycle_stats = active_users.groupby('lifecycle_stage').agg({ 'user_id': 'count', 'total_amount': ['sum', 'mean'], 'order_count': 'mean' }).reset_index() lifecycle_stats.columns = ['生命周期阶段', '用户数', '消费总额', '人均消费', '人均订单数'] lifecycle_stats['用户占比%'] = (lifecycle_stats['用户数'] / lifecycle_stats['用户数'].sum() * 100).round(1) print("=== 生命周期阶段分布 ===") print(lifecycle_stats.to_string(index=False)) # 计算LTV avg_revenue = active_users['total_amount'].mean() avg_lifetime_days = active_users['R'].mean() ltv_estimate = avg_revenue * (365 / avg_lifetime_days) / 12 * 24 # 估算24个月LTV print(f"\n=== 用户价值评估 ===") print(f"人均消费: {avg_revenue:.2f}元") print(f"估算LTV(24月): {ltv_estimate:.2f}元")

五、运营策略建议

4 输出差异化运营策略
# ======================================== # 5. 运营策略建议生成 # ======================================== def generate_strategy_report(segment_stats, lifecycle_stats): """生成运营策略报告""" report = """ ======================================== 电商平台用户价值分析报告 ======================================== 一、用户概况 ------------ - 总用户数: 10,000人 - 活跃用户: {active_users}人 - 活跃率: {active_rate}% - 总销售额: {total_revenue:,.0f}元 二、RFM分层分析 --------------- """.format( active_users=len(active_users), active_rate=len(active_users) / len(user_profile) * 100, total_revenue=active_users['total_amount'].sum() ) for _, row in segment_stats.head(4).iterrows(): report += "- {}: {}人 ({}%), 贡献{}%销售额\n".format( row['用户分层'], row['用户数'], row['用户占比%'], row['金额占比%'] ) report += """ 三、生命周期分析 ---------------- """ for _, row in lifecycle_stats.iterrows(): report += "- {}: {}人 ({}%), 人均消费{:.0f}元\n".format( row['生命周期阶段'], row['用户数'], row['用户占比%'], row['人均消费'] ) report += """ 四、运营策略建议 ---------------- 【重要价值用户】 - 策略: VIP专属服务、会员特权、生日关怀 - 目标: 维持高忠诚度，延长成熟期 【重要保持用户】 - 策略: 主动触达、流失预警、定向召回 - 目标: 防止流失，重新激活 【重要发展用户】 - 策略: 提升复购、品类推荐、会员引导 - 目标: 提升消费频次，转化为价值用户 【一般用户】 - 策略: 促销推送、新品推荐、活动触达 - 目标: 提升活跃度，培养消费习惯 【低价值用户】 - 策略: 低成本维护、自动化营销 - 目标: 控制运营成本，选择性激活 ======================================== 报告生成时间: 2024-12-31 ======================================== """ return report # 生成报告 strategy_report = generate_strategy_report(segment_stats, lifecycle_stats) print(strategy_report)
案例总结

本案例完整展示了用户价值分析的流程：

  1. 数据准备：整合用户基础信息和订单数据，进行数据清洗
  2. 用户画像：构建年龄、消费能力、活跃度等维度的用户标签
  3. RFM分层：计算RFM指标，将用户分为8个价值层级
  4. 生命周期：识别用户所处的生命周期阶段
  5. 策略建议：针对不同用户群体制定差异化运营策略

注意事项：实际项目中需要注意：1) 数据质量问题，如缺失值、异常值处理；2) RFM打分阈值需要根据业务特点调整；3) 用户分层结果需要定期更新；4) 运营策略需要结合业务资源和目标制定。

综合测验

在用户价值分析中，RFM分层与用户生命周期管理的关系是？

两者是完全独立的分析方法
RFM可用于识别用户生命周期阶段，两者相辅相成
RFM只适用于新用户，生命周期管理只适用于老用户
两者只能选择其一进行分析

解析：RFM模型与用户生命周期管理是相辅相成的。RFM分值可以用来识别用户所处的生命周期阶段（如高R低F低M可能是引入期用户），两者结合可以更全面地理解用户价值并制定运营策略。
