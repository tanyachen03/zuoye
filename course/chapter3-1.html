市场集中度分析

掌握CRn和HHI两大核心指标，学会量化评估市场竞争格局，识别垄断与竞争市场结构

本节目标

  • 理解市场集中度的概念与意义
  • 掌握CRn集中度指标的计算与应用
  • 掌握HHI指数的计算与解读
  • 能够识别不同的市场结构类型
  • 运用Python进行市场集中度分析

一、市场集中度概述

什么是市场集中度

市场集中度（Market Concentration）是指某一行业中少数几家最大企业所占的市场份额，是衡量市场竞争程度的重要指标。集中度越高，市场竞争越不充分；集中度越低，市场竞争越激烈。

市场集中度分析对于企业战略决策、投资分析、反垄断监管等领域具有重要意义：

企业战略：判断行业竞争格局，制定竞争策略
投资分析：评估行业盈利能力和投资价值
反垄断监管：识别垄断行为，维护市场公平
市场研究：了解行业结构和发展趋势
市场结构类型与集中度关系
完全竞争 CR4 < 30%
垄断竞争 CR4 30-50%
寡头垄断 CR4 50-80%
完全垄断 CR4 > 80%

二、CRn集中度指标

CRn指标定义

CRn（Concentration Ratio）即行业集中度指数，是指行业中前n家最大企业的市场份额之和。最常用的是CR4（前4家企业）和CR8（前8家企业）。

CRn = (X1 + X2 + ... + Xn) / X总 × 100%
其中 Xi 为第i家企业的销售额/产量，X总 为行业总销售额/总产量

CRn指标评判标准

CR4值 CR8值 市场结构 竞争程度
CR4 < 30% CR8 < 40% 竞争型市场 高度竞争
30% ≤ CR4 < 50% 40% ≤ CR8 < 60% 低集中寡占型 竞争较充分
50% ≤ CR4 < 70% 60% ≤ CR8 < 80% 中集中寡占型 竞争一般
70% ≤ CR4 < 90% 80% ≤ CR8 < 100% 高集中寡占型 竞争不充分
CR4 ≥ 90% CR8 ≥ 100% 极高集中寡占型 接近垄断

Python计算CRn指标

# 计算CRn集中度指标 import pandas as pd import numpy as np # 某行业企业销售数据（单位：亿元） market_data = { '企业': ['企业A', '企业B', '企业C', '企业D', '企业E', '企业F', '企业G', '企业H', '其他'], '销售额': [500, 350, 280, 200, 150, 120, 80, 50, 270] } df = pd.DataFrame(market_data) # 按销售额降序排列 df = df.sort_values('销售额', ascending=False).reset_index(drop=True) # 计算市场份额 total_sales = df['销售额'].sum() df['市场份额(%)'] = (df['销售额'] / total_sales * 100).round(2) # 计算CR4和CR8 CR4 = df.head(4)['市场份额(%)'].sum() CR8 = df.head(8)['市场份额(%)'].sum() print("=== 市场份额排名 ===") print(df) print(f"\nCR4 = {CR4:.2f}%") print(f"CR8 = {CR8:.2f}%") # 判断市场结构 if CR4 < 30: structure = "竞争型市场" elif CR4 < 50: structure = "低集中寡占型" elif CR4 < 70: structure = "中集中寡占型" elif CR4 < 90: structure = "高集中寡占型" else: structure = "极高集中寡占型" print(f"市场结构判断: {structure}")

小贴士：CRn指标计算简单、易于理解，但存在局限性：只考虑前n家企业，忽略了其他企业的分布情况；无法区分"几家独大"和"多家均衡"的市场格局差异。

三、HHI指数

HHI指数定义

HHI指数（Herfindahl-Hirschman Index）即赫芬达尔-赫希曼指数，是衡量市场集中度的综合指标，考虑了所有企业的市场份额，能够更全面地反映市场结构。

HHI = S12 + S22 + ... + Sn2 = ΣSi2
其中 Si 为第i家企业的市场份额百分比，HHI取值范围：0 ~ 10000

HHI指数评判标准

HHI值范围 市场类型 竞争状况 监管关注
HHI < 1000 低集中度市场 竞争充分 无需关注
1000 ≤ HHI < 1800 中集中度市场 竞争较充分 适度关注
HHI ≥ 1800 高集中度市场 竞争不充分 重点关注

Python计算HHI指数

# 计算HHI指数 import pandas as pd # 使用前面的市场数据 market_data = { '企业': ['企业A', '企业B', '企业C', '企业D', '企业E', '企业F', '企业G', '企业H', '其他'], '销售额': [500, 350, 280, 200, 150, 120, 80, 50, 270] } df = pd.DataFrame(market_data) # 计算市场份额百分比 total_sales = df['销售额'].sum() df['市场份额'] = df['销售额'] / total_sales * 100 # 计算HHI指数 HHI = (df['市场份额'] ** 2).sum() print(f"HHI指数 = {HHI:.2f}") # 判断市场集中度 if HHI < 1000: concentration = "低集中度市场" elif HHI < 1800: concentration = "中集中度市场" else: concentration = "高集中度市场" print(f"市场集中度判断: {concentration}") # HHI变化分析（模拟并购影响） print("\n=== 并购影响分析 ===") print("如果企业A并购企业B，HHI将增加:") delta_HHI = (df.loc[0, '市场份额'] + df.loc[1, '市场份额'])**2 - \ df.loc[0, '市场份额']**2 - df.loc[1, '市场份额']**2 print(f"ΔHHI = {delta_HHI:.2f}") print(f"并购后HHI = {HHI + delta_HHI:.2f}")

常见错误：计算HHI时，市场份额应该用百分比数值（如25.5），而不是小数形式（如0.255）。如果用小数形式计算，HHI值会非常小，无法与标准判断准则对应。

四、真实商业案例

案例：中国智能手机市场集中度分析

背景：2023年中国智能手机市场出货量数据，让我们分析市场集中度情况。

排名 品牌 出货量（百万台） 市场份额
1荣耀44.517.1%
2OPPO43.016.5%
3苹果42.016.1%
4vivo39.515.2%
5小米35.013.4%
6华为25.09.6%
7其他31.011.9%
# 中国智能手机市场集中度分析 import pandas as pd # 2023年中国智能手机市场数据 phone_data = { '品牌': ['荣耀', 'OPPO', '苹果', 'vivo', '小米', '华为', '其他'], '出货量': [44.5, 43.0, 42.0, 39.5, 35.0, 25.0, 31.0], '市场份额': [17.1, 16.5, 16.1, 15.2, 13.4, 9.6, 11.9] } df = pd.DataFrame(phone_data) # 计算CR4 CR4 = df.head(4)['市场份额'].sum() print(f"CR4 = {CR4:.1f}%") # 计算HHI HHI = (df['市场份额'] ** 2).sum() print(f"HHI = {HHI:.2f}") print("\n=== 分析结论 ===") print(f"1. CR4={CR4:.1f}%，属于中集中寡占型市场") print(f"2. HHI={HHI:.0f}，市场集中度适中") print("3. 前六名品牌占据88%市场份额，竞争激烈") print("4. 各品牌份额相近，无明显垄断者")

案例洞察：中国智能手机市场呈现"多强争霸"格局，CR4约65%属于中集中寡占型市场，但HHI约1200处于中等集中度，说明各品牌份额相对均衡，竞争激烈。这种市场结构下，企业需要持续创新才能保持竞争优势。

五、CRn与HHI的对比

两种指标各有优劣，实际分析中建议结合使用：

对比维度 CRn指标 HHI指数
计算复杂度 简单 中等
数据要求 仅需前n家企业 需要全部企业数据
信息完整性 较低 较高
敏感性 对份额变化不敏感 对份额变化敏感
适用场景 快速判断市场结构 反垄断分析、并购评估

注意：在进行市场集中度分析时，首先要明确"市场边界"的定义。产品市场范围（如智能手机vs功能手机）和地理市场范围（如全国市场vs区域市场）的定义会直接影响分析结果。
