Pandas数据结构：Series和DataFrame

掌握Pandas的核心数据结构，学会使用Series和DataFrame进行灵活的数据操作

本节目标

  • 理解Series和DataFrame的概念和特点
  • 掌握创建Series和DataFrame的多种方法
  • 学会DataFrame的索引、选择和过滤操作
  • 掌握数据的基本操作：增删改查
  • 了解常用数据类型的处理方法

一、Pandas简介

为什么选择Pandas

Pandas是Python数据分析的核心库，提供了两种主要的数据结构：Series（一维）和DataFrame（二维）。它是处理表格数据的最佳选择。

表格数据处理 - 类似Excel的数据操作体验
灵活的IO - 支持CSV、Excel、SQL等多种格式
数据清洗 - 强大的缺失值和异常值处理
数据聚合 - 类SQL的分组聚合操作
import pandas as pd import numpy as np # 查看Pandas版本 print(pd.__version__)

二、Series一维数据结构

创建Series

Series是带标签的一维数组，可以存储任意数据类型。它由值（values）和索引（index）两部分组成。

import pandas as pd # 从列表创建Series s1 = pd.Series([10, 20, 30, 40, 50]) print("默认索引:") print(s1) # 指定索引 s2 = pd.Series([10, 20, 30], index=['a', 'b', 'c']) print("\n自定义索引:") print(s2) # 从字典创建Series data = {'北京': 2154, '上海': 2487, '广州': 1530} s3 = pd.Series(data) print("\n从字典创建:") print(s3) # 指定名称 s4 = pd.Series([100, 200, 300], name='销售额') print("\n带名称的Series:") print(s4)

Series索引操作

import pandas as pd s = pd.Series([100, 200, 300, 400, 500], index=['a', 'b', 'c', 'd', 'e']) # 通过标签索引 print("标签索引 'b':", s['b']) print("多个标签:", s[['a', 'c']]) # 通过位置索引 print("位置索引 [0]:", s.iloc[0]) print("切片 [1:3]:", s.iloc[1:3]) # 布尔索引 print("大于250:", s[s > 250]) # Series属性 print("\n值:", s.values) print("索引:", s.index.tolist()) print("数据类型:", s.dtype)

小贴士：使用 .loc[] 进行标签索引，使用 .iloc[] 进行位置索引，可以避免混淆，代码更清晰。

三、DataFrame二维数据结构

创建DataFrame

DataFrame是二维表格数据结构，有行索引和列索引，可以看作是由多个Series组成的字典。

import pandas as pd import numpy as np # 从字典创建 data = { '姓名': ['张三', '李四', '王五', '赵六'], '年龄': [25, 30, 28, 35], '城市': ['北京', '上海', '广州', '深圳'], '薪资': [15000, 20000, 18000, 25000] } df = pd.DataFrame(data) print(df) # 指定列顺序 df = pd.DataFrame(data, columns=['姓名', '城市', '年龄', '薪资']) # 指定行索引 df = pd.DataFrame(data, index=['A', 'B', 'C', 'D']) # 从列表的列表创建 data2 = [ ['张三', 25, '北京'], ['李四', 30, '上海'], ['王五', 28, '广州'] ] df2 = pd.DataFrame(data2, columns=['姓名', '年龄', '城市'])

查看数据

import pandas as pd # 创建示例数据 df = pd.DataFrame({ 'product': ['A', 'B', 'C', 'D', 'E'], 'sales': [100, 150, 200, 130, 180], 'profit': [20, 35, 50, 25, 40] }) # 查看前几行 print(df.head(3)) # 查看后几行 print(df.tail(2)) # 查看数据信息 print(df.info()) # 查看统计摘要 print(df.describe()) # 查看列名和数据类型 print("列名:", df.columns.tolist()) print("数据类型:\n", df.dtypes) print("形状:", df.shape)

数据选择与过滤

import pandas as pd df = pd.DataFrame({ 'name': ['Alice', 'Bob', 'Charlie', 'David'], 'age': [25, 30, 35, 28], 'city': ['北京', '上海', '广州', '深圳'], 'salary': [15000, 20000, 25000, 18000] }) # 选择单列 print("选择单列:") print(df['name']) # 返回Series # 选择多列 print("\n选择多列:") print(df[['name', 'salary']]) # 返回DataFrame # 使用loc标签索引 print("\nloc选择行:") print(df.loc[0]) # 第一行 print(df.loc[0:2, ['name', 'age']]) # 指定行列 # 使用iloc位置索引 print("\niloc选择:") print(df.iloc[0]) # 第一行 print(df.iloc[0:2, 0:2]) # 前两行前两列 # 条件过滤 print("\n条件过滤:") print(df[df['age'] > 28]) print(df[(df['age'] > 25) & (df['salary'] > 18000)]) # 使用isin方法 print("\nisin筛选:") print(df[df['city'].isin(['北京', '上海'])])

常见错误：使用 df[0] 选择行会报错，因为这是选择列的语法。正确做法是使用 df.iloc[0] 或 df.loc[0]。

四、数据增删改操作

添加数据

import pandas as pd df = pd.DataFrame({ 'name': ['Alice', 'Bob'], 'age': [25, 30] }) # 添加新列 df['city'] = ['北京', '上海'] df['salary'] = [15000, 20000] # 基于现有列创建新列 df['annual_salary'] = df['salary'] * 12 # 使用assign方法（链式操作） df = df.assign( bonus = df['salary'] * 0.1, level = ['Junior', 'Senior'] ) # 添加新行 new_row = {'name': 'Charlie', 'age': 28, 'city': '广州'} df = pd.concat([df, pd.DataFrame([new_row])], ignore_index=True) print(df)

修改数据

import pandas as pd df = pd.DataFrame({ 'name': ['Alice', 'Bob', 'Charlie'], 'age': [25, 30, 35], 'salary': [15000, 20000, 25000] }) # 修改单个值 df.loc[0, 'age'] = 26 # 修改整列 df['salary'] = df['salary'] * 1.1 # 涨薪10% # 条件修改 df.loc[df['age'] > 30, 'salary'] = df['salary'] * 1.2 # 使用replace方法 df['name'] = df['name'].replace({'Alice': '爱丽丝'}) print(df)

删除数据

import pandas as pd df = pd.DataFrame({ 'name': ['Alice', 'Bob', 'Charlie', 'David'], 'age': [25, 30, 35, 28], 'city': ['北京', '上海', '广州', '深圳'] }) # 删除列 df_dropped = df.drop(columns=['city']) print("删除列后:") print(df_dropped) # 删除行 df_dropped = df.drop(index=[0, 2]) # 删除第0行和第2行 print("\n删除行后:") print(df_dropped) # 原地删除 df.drop(columns=['age'], inplace=True) # 删除缺失值 df_with_na = pd.DataFrame({ 'A': [1, None, 3], 'B': [4, 5, None] }) print("\n删除缺失值:") print(df_with_na.dropna()) # 删除重复值 df_dup = pd.DataFrame({ 'A': [1, 1, 2, 2], 'B': ['a', 'a', 'b', 'b'] }) print("\n删除重复值:") print(df_dup.drop_duplicates())

五、数据类型处理

常见数据类型

Pandas支持多种数据类型，了解和正确处理数据类型对于数据分析至关重要：

Pandas类型 说明 示例
int64 整数类型 年龄、数量
float64 浮点数类型 价格、比率
object 字符串/混合类型 姓名、地址
bool 布尔类型 是否会员
datetime64 日期时间类型 订单日期
category 分类类型 性别、等级
import pandas as pd df = pd.DataFrame({ 'date': ['2024-01-01', '2024-01-02'], 'price': ['100.5', '200.8'], 'category': ['A', 'B'] }) # 查看数据类型 print(df.dtypes) # 转换数据类型 df['date'] = pd.to_datetime(df['date']) df['price'] = df['price'].astype('float') df['category'] = df['category'].astype('category') print("\n转换后:") print(df.dtypes) # 使用astype批量转换 df = df.astype({ 'price': 'float64', 'category': 'category' })

小贴士：对于有限取值的字符串列（如性别、省份、等级），转换为 category 类型可以节省内存并提高计算效率。

真实商业案例：电商订单数据处理

背景：某电商平台需要处理每日订单数据，进行数据清洗和基础分析。

原始数据问题

  • 订单金额存储为字符串格式
  • 日期格式不统一
  • 部分字段存在空值

处理代码

import pandas as pd import numpy as np # 模拟原始订单数据 orders = pd.DataFrame({ 'order_id': ['ORD001', 'ORD002', 'ORD003', 'ORD004'], 'customer': ['张三', '李四', None, '王五'], 'amount': ['¥1,299.00', '¥599.50', '¥2,580.00', '¥899.00'], 'order_date': ['2024/01/15', '2024-01-16', '2024.01.17', '2024/01/18'], 'status': ['已完成', '配送中', '已完成', '待付款'] }) # 1. 清理金额字段 orders['amount_clean'] = ( orders['amount'] .str.replace('¥', '') .str.replace(',', '') .astype('float') ) # 2. 统一日期格式 orders['order_date'] = pd.to_datetime(orders['order_date']) # 3. 处理缺失值 orders['customer'] = orders['customer'].fillna('未知用户') # 4. 添加派生字段 orders['month'] = orders['order_date'].dt.month orders['weekday'] = orders['order_date'].dt.day_name() # 5. 基础统计 print("订单金额统计:") print(orders['amount_clean'].describe()) print("\n处理后的数据:") print(orders)

处理结果

通过Pandas的数据处理功能，成功将杂乱的原始数据转换为可用于分析的干净数据，为后续分析奠定了基础。

知识点测验

以下哪种方式可以正确选择DataFrame的第一行数据？

df[0]
df[1]
df.iloc[0]
df.loc[1]

解析：df[0] 会尝试选择名为"0"的列而不是行。df.iloc[0] 使用位置索引选择第一行（索引从0开始）。df.loc[1] 是选择行标签为1的行，不是第一行。

知识点测验

Series和DataFrame的主要区别是什么？

Series可以存储多种数据类型，DataFrame只能存储一种
Series是一维数据结构，DataFrame是二维表格数据结构
DataFrame是Series的子类
它们没有区别，只是名称不同

解析：Series是一维带标签的数组，只能有一列数据；DataFrame是二维表格结构，可以有多行多列，可以看作是由多个Series组成的字典。
