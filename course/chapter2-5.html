数据合并与分组聚合

掌握Pandas的数据合并和分组聚合技术，实现复杂的数据分析任务

本节目标

  • 掌握concat、merge、join三种数据合并方法
  • 理解不同类型的连接方式及其应用场景
  • 学会使用groupby进行数据分组
  • 掌握常用的聚合函数和自定义聚合
  • 能够进行多级分组和透视表操作

一、数据合并概述

实际业务中，数据通常分散在多个表或文件中，需要将它们合并后才能进行完整分析。Pandas提供了多种数据合并方法。

concat - 沿轴方向拼接多个DataFrame
merge - 基于共同列进行SQL风格连接
join - 基于索引进行快速连接

二、concat数据拼接

纵向与横向拼接

import pandas as pd # 创建示例数据 df1 = pd.DataFrame({'name': ['张三', '李四'], 'age': [25, 30]}) df2 = pd.DataFrame({'name': ['王五', '赵六'], 'age': [28, 35]}) # 纵向拼接 result = pd.concat([df1, df2], ignore_index=True) print(result) # 横向拼接 df3 = pd.DataFrame({'city': ['北京', '上海']}) result_h = pd.concat([df1, df3], axis=1) print(result_h)

小贴士：使用 ignore_index=True 可以重置索引，避免索引重复。

三、merge数据连接

连接类型

inner

内连接
交集

left

左连接
保留左表

right

右连接
保留右表

outer

外连接
并集

import pandas as pd orders = pd.DataFrame({ 'order_id': ['O001', 'O002', 'O003'], 'customer_id': ['C001', 'C002', 'C001'], 'amount': [500, 800, 600] }) customers = pd.DataFrame({ 'customer_id': ['C001', 'C002'], 'name': ['张三', '李四'], 'city': ['北京', '上海'] }) # 内连接 inner = pd.merge(orders, customers, on='customer_id') print(inner) # 左连接 left = pd.merge(orders, customers, on='customer_id', how='left') print(left)

常见错误：忘记指定how参数时默认使用内连接，可能导致数据丢失。建议始终显式指定连接类型。

四、groupby分组操作

分组与聚合

import pandas as pd df = pd.DataFrame({ 'department': ['销售部', '销售部', '技术部', '技术部'], 'employee': ['张三', '李四', '王五', '赵六'], 'sales': [100, 150, 80, 120] }) # 分组求和 print(df.groupby('department')['sales'].sum()) # 多重聚合 print(df.groupby('department').agg({ 'sales': ['sum', 'mean', 'count'] }))

五、透视表

import pandas as pd df = pd.DataFrame({ 'region': ['华东', '华东', '华南', '华南'], 'product': ['A', 'B', 'A', 'B'], 'sales': [100, 150, 120, 180] }) # 透视表 pivot = pd.pivot_table(df, values='sales', index='region', columns='product', aggfunc='sum', fill_value=0) print(pivot)

真实商业案例：多表关联销售分析

背景：某电商公司需要分析各区域、各品类的销售情况，数据分散在订单表、客户表、商品表中。

import pandas as pd orders = pd.DataFrame({ 'order_id': ['O001', 'O002', 'O003'], 'customer_id': ['C001', 'C002', 'C001'], 'product_id': ['P001', 'P002', 'P003'], 'amount': [200, 500, 300] }) customers = pd.DataFrame({ 'customer_id': ['C001', 'C002'], 'region': ['华东', '华南'] }) # 合并分析 merged = pd.merge(orders, customers, on='customer_id') region_sales = merged.groupby('region')['amount'].sum() print(region_sales)
