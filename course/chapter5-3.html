关联规则与购物篮分析

掌握Apriori算法原理，发现商品间的关联关系，优化商品组合策略

本节目标

  • 理解关联规则分析的基本概念和应用场景
  • 掌握支持度、置信度、提升度的计算方法
  • 理解Apriori算法的核心原理
  • 能够使用Python实现购物篮分析
  • 学会解读关联规则并制定营销策略

一、关联规则概述

什么是购物篮分析

购物篮分析（Market Basket Analysis）是数据挖掘中的经典应用，通过分析顾客购买行为，发现商品之间的关联关系。最著名的案例是"啤酒与尿布"的故事。

关联规则的形式为：{A} → {B}，表示"购买A的顾客倾向于同时购买B"。

啤酒

尿布

应用场景

商品陈列：关联商品放置在相邻位置
捆绑销售：打包促销关联商品
精准推荐：购买A后推荐B
库存管理：关联商品协调补货

二、核心指标详解

支持度（Support）

支持度表示同时购买A和B的交易占总交易的比例，反映规则的普遍性。

Support(A → B) = P(A ∪ B) = 包含A和B的交易数 / 总交易数
支持度衡量规则出现的频率

置信度（Confidence）

置信度表示购买A的顾客中同时购买B的比例，反映规则的可靠性。

Confidence(A → B) = P(B|A) = 包含A和B的交易数 / 包含A的交易数
置信度衡量规则的准确程度

提升度（Lift）

提升度表示A出现时B出现的概率是B单独出现概率的多少倍，反映规则的有效性。

Lift(A → B) = P(B|A) / P(B) = Confidence(A → B) / Support(B)
提升度 > 1 表示正相关，< 1 表示负相关，= 1 表示无关联
指标解读指南

支持度

≥ 1% 通常认为有意义
过低则规则不具普遍性

置信度

≥ 50% 表示强关联
但需结合提升度判断

提升度

> 1.5 表示有价值的关联
越大关联性越强

小贴士：一个优质的关联规则应该同时满足：支持度 ≥ 阈值、置信度 ≥ 阈值、提升度 > 1。只看置信度可能会产生误导，因为热门商品本身购买率就高。

三、Apriori算法原理

算法核心思想

Apriori算法是最经典的关联规则挖掘算法，基于先验原理：

  • 如果一个项集是频繁的，则它的所有子集也是频繁的
  • 如果一个项集是不频繁的，则它的所有超集也是不频繁的
Apriori算法流程
扫描数据库
统计1-项集支持度
筛选频繁1-项集
(支持度 ≥ 阈值)
生成候选k-项集
连接+剪枝
重复直到
无新频繁项集
生成关联规则
计算置信度

算法示例

假设有以下5笔交易数据：

交易ID 购买商品
T1牛奶, 面包, 黄油
T2牛奶, 面包
T3牛奶, 鸡蛋
T4面包, 鸡蛋
T5牛奶, 面包, 鸡蛋

设最小支持度为40%（2笔交易），则：

  • 牛奶出现4次，支持度=80%，频繁
  • 面包出现4次，支持度=80%，频繁
  • {牛奶, 面包}出现3次，支持度=60%，频繁

四、Python实现购物篮分析

使用mlxtend库实现

下面是使用Python和mlxtend库进行购物篮分析的完整代码：

# ======================================== # 关联规则与购物篮分析 - 完整实现 # ======================================== import pandas as pd import numpy as np from itertools import combinations # 1. 准备交易数据 transactions = [ ['牛奶', '面包', '黄油'], ['牛奶', '面包'], ['牛奶', '鸡蛋'], ['面包', '鸡蛋'], ['牛奶', '面包', '鸡蛋'], ['牛奶', '鸡蛋', '黄油'], ['面包', '黄油'], ['牛奶', '面包', '黄油', '鸡蛋'], ['牛奶', '面包'], ['面包', '鸡蛋'] ] # 2. 转换为one-hot编码格式 def create_basket_matrix(transactions): """将交易列表转换为购物篮矩阵""" all_items = set() for trans in transactions: all_items.update(trans) all_items = sorted(list(all_items)) basket_data = [] for trans in transactions: row = {item: 1 if item in trans else 0 for item in all_items} basket_data.append(row) return pd.DataFrame(basket_data) basket_df = create_basket_matrix(transactions) print("购物篮矩阵：") print(basket_df) print(f"\n总交易数: {len(transactions)}") # 3. 计算支持度 def calculate_support(df, items): """计算项集的支持度""" if len(items) == 1: return df[items[0]].mean() mask = df[items].all(axis=1) return mask.mean() # 4. 计算置信度 def calculate_confidence(df, antecedent, consequent): """计算关联规则的置信度""" support_both = calculate_support(df, antecedent + consequent) support_ant = calculate_support(df, antecedent) if support_ant == 0: return 0 return support_both / support_ant # 5. 计算提升度 def calculate_lift(df, antecedent, consequent): """计算关联规则的提升度""" confidence = calculate_confidence(df, antecedent, consequent) support_cons = calculate_support(df, consequent) if support_cons == 0: return 0 return confidence / support_cons # 6. 生成关联规则 def generate_rules(df, min_support=0.3, min_confidence=0.5, min_lift=1.0): """生成满足条件的关联规则""" items = list(df.columns) rules = [] # 遍历所有可能的规则 for size in range(1, len(items)): for antecedent in combinations(items, size): remaining = [i for i in items if i not in antecedent] for consequent in combinations(remaining, 1): ant_list = list(antecedent) con_list = list(consequent) support = calculate_support(df, ant_list + con_list) confidence = calculate_confidence(df, ant_list, con_list) lift = calculate_lift(df, ant_list, con_list) if support >= min_support and confidence >= min_confidence and lift >= min_lift: rules.append({ '规则': f"{set(ant_list)} → {set(con_list)}", '前项': set(ant_list), '后项': set(con_list), '支持度': round(support, 3), '置信度': round(confidence, 3), '提升度': round(lift, 3) }) return pd.DataFrame(rules).sort_values('提升度', ascending=False) # 7. 执行分析 print("\n" + "=" * 60) print("关联规则分析结果") print("=" * 60) rules_df = generate_rules(basket_df, min_support=0.2, min_confidence=0.4, min_lift=1.0) print(rules_df[['规则', '支持度', '置信度', '提升度']])

使用mlxtend库（推荐）

# 使用mlxtend库进行关联规则挖掘 from mlxtend.frequent_patterns import apriori, association_rules # 挖掘频繁项集 frequent_itemsets = apriori(basket_df, min_support=0.2, use_colnames=True) print("频繁项集：") print(frequent_itemsets.sort_values('support', ascending=False)) # 生成关联规则 rules = association_rules(frequent_itemsets, metric="lift", min_threshold=1.0) rules = rules.sort_values(['lift', 'confidence'], ascending=[False, False]) print("\n关联规则：") print(rules[['antecedents', 'consequents', 'support', 'confidence', 'lift']].head(10))

结果可视化

# 关联规则可视化 import matplotlib.pyplot as plt plt.rcParams['font.sans-serif'] = ['SimHei'] plt.rcParams['axes.unicode_minus'] = False fig, axes = plt.subplots(1, 2, figsize=(14, 5)) # 支持度 vs 置信度散点图 ax1 = axes[0] scatter = ax1.scatter(rules['support'], rules['confidence'], c=rules['lift'], cmap='RdYlGn', s=100, alpha=0.7) ax1.set_xlabel('支持度') ax1.set_ylabel('置信度') ax1.set_title('支持度 vs 置信度（颜色=提升度）') plt.colorbar(scatter, ax=ax1, label='提升度') # 提升度分布 ax2 = axes[1] ax2.bar(range(len(rules)), rules['lift'].sort_values(ascending=False)) ax2.axhline(y=1, color='r', linestyle='--', label='提升度=1') ax2.set_xlabel('规则排名') ax2.set_ylabel('提升度') ax2.set_title('关联规则提升度排名') ax2.legend() plt.tight_layout() plt.show()

五、真实商业案例

案例：超市商品关联分析

背景：某大型超市希望通过分析顾客购买数据，优化商品陈列和促销策略。

发现的关联规则

规则 支持度 置信度 提升度 商业价值
{牛奶} → {面包} 32% 68% 2.1 强关联，可捆绑促销
{尿布} → {啤酒} 8% 45% 3.2 年轻父亲群体特征
{薯片} → {可乐} 15% 52% 1.8 休闲食品组合
{牙膏} → {牙刷} 12% 61% 2.5 日用品组合

应用策略

商品陈列：将关联商品放置在相邻货架
捆绑销售：创建"早餐组合"、"零食套餐"
智能推荐：POS系统自动推荐关联商品
促销规划：关联商品联合促销

案例启示：通过关联规则分析，该超市实施了商品重新陈列和捆绑促销策略，客单价提升了15%，关联商品销量增长22%。

六、注意事项与最佳实践

常见陷阱

常见错误：

  • 忽视提升度：只看置信度可能发现"伪关联"，热门商品本身购买率高
  • 阈值设置不当：支持度过高会漏掉有价值的规则，过低会产生大量无效规则
  • 忽视业务含义：有些规则虽然指标好，但业务上没有意义或无法执行
  • 忽略时间维度：商品关联可能随季节、节日变化

最佳实践

设置合理阈值：支持度1%-5%，置信度40%-60%，提升度>1.2
结合业务知识：与业务人员一起解读规则
分时段分析：工作日/周末、节假日单独分析
持续迭代：定期更新规则库
知识点测验

关联规则中，"购买A的顾客中同时购买B的比例"称为？

支持度
置信度
提升度
覆盖率

解析：置信度(Confidence) = P(B|A)，表示在购买A的条件下购买B的概率，即购买A的顾客中同时购买B的比例。

知识点测验

当提升度Lift(A→B) = 2时，表示什么？

A和B没有关联
A和B负相关
购买A时购买B的概率是B单独出现概率的2倍
B的购买率是50%

解析：提升度 = 置信度 / 支持度(B)。Lift=2表示购买A时购买B的概率是B单独出现概率的2倍，说明A和B存在正关联。
