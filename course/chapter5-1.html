商品ABC分析

掌握ABC分类法的原理与Python实现，学会商品分级管理策略

本节目标

  • 理解ABC分类法的基本原理和帕累托法则

  • 学会解读ABC分析结果并制定运营建议

一、ABC分类法概述

什么是ABC分类法

ABC分类法（ABC Analysis）是一种基于帕累托法则（二八定律）的库存管理方法。它将商品按照重要程度分为A、B、C三类，帮助企业实现差异化管理。

帕累托法则指出：约20%的商品贡献了约80%的销售额，这20%的商品就是需要重点关注的A类商品。

ABC分类示意图
80%

A类商品

占品种10-20%

15%

B类商品

占品种20-30%

C类商品

占品种50-60%

ABC分类标准

ABC分类通常按照销售额（或销售量、利润等指标）进行划分，具体标准如下：

类别 销售额占比 品种占比 管理策略
A类 70%-80% 10%-20% 重点管理、严格控制库存
B类 15%-20% 20%-30% 常规管理、定期检查
C类 5%-10% 50%-60% 简化管理、批量采购

小贴士：ABC分类的阈值可以根据企业实际情况调整。有些企业采用更细分的A+、A、B、C、D五类分类法，以实现更精细的管理。

二、ABC分类计算公式

核心计算步骤

ABC分类的计算过程包括以下关键步骤：

  1. 计算各商品销售额：销售额 = 单价 × 销售量
  2. 按销售额降序排列：从高到低排序
  3. 计算累计销售额：逐项累加销售额
  4. 计算累计销售额占比：累计销售额 / 总销售额 × 100%
  5. 确定ABC类别：根据累计占比划分类别
ABC分类计算流程
原始销售数据
计算销售额并排序
计算累计占比
划分ABC类别

关键公式

销售额计算：

销售额i = 单价i × 销售量i

累计销售额占比：

累计占比i = (∑j=1i 销售额j) / 总销售额 × 100%

三、Python实现ABC分析

完整代码实现

下面是使用Python实现商品ABC分析的完整代码，包含数据生成、分类计算和结果可视化：

# ======================================== # 商品ABC分析 - 完整实现 # ======================================== import pandas as pd import numpy as np # 1. 准备示例数据 data = { '商品ID': ['P001', 'P002', 'P003', 'P004', 'P005', 'P006', 'P007', 'P008', 'P009', 'P010'], '商品名称': ['高端手机', '笔记本电脑', '平板电脑', '智能手表', '无线耳机', '充电宝', '手机壳', '数据线', '屏幕贴膜', '清洁套装'], '单价': [5999, 8999, 3999, 2999, 1299, 199, 49, 29, 19, 15], '销售量': [150, 80, 200, 120, 500, 800, 2000, 3000, 5000, 4000] } df = pd.DataFrame(data) # 2. 计算销售额 df['销售额'] = df['单价'] * df['销售量'] # 3. 按销售额降序排列 df = df.sort_values('销售额', ascending=False).reset_index(drop=True) # 4. 计算累计销售额和累计占比 df['累计销售额'] = df['销售额'].cumsum() total_sales = df['销售额'].sum() df['销售额占比(%)'] = (df['销售额'] / total_sales * 100).round(2) df['累计占比(%)'] = (df['累计销售额'] / total_sales * 100).round(2) # 5. ABC分类函数 def classify_abc(cumulative_pct): """根据累计占比划分ABC类别""" if cumulative_pct <= 80: return 'A' elif cumulative_pct <= 95: return 'B' else: return 'C' df['ABC类别'] = df['累计占比(%)'].apply(classify_abc) # 6. 输出分析结果 print("=" * 60) print("商品ABC分析结果") print("=" * 60) print(df[['商品名称', '销售额', '销售额占比(%)', '累计占比(%)', 'ABC类别']]) # 7. 统计各类别情况 print("\n" + "=" * 60) print("各类别统计汇总") print("=" * 60) summary = df.groupby('ABC类别').agg({ '商品ID': 'count', '销售额': 'sum' }).rename(columns={'商品ID': '商品数量'}) summary['品种占比(%)'] = (summary['商品数量'] / len(df) * 100).round(1) summary['销售额占比(%)'] = (summary['销售额'] / total_sales * 100).round(1) summary = summary.sort_index() print(summary)

四、真实商业案例

案例：某电商平台商品管理优化

背景：某电商平台拥有5000+SKU，库存周转率低，资金占用严重。运营团队决定采用ABC分类法优化商品管理。

案例数据概览

A类商品

520个SKU

贡献78%销售额

B类商品

1250个SKU

贡献17%销售额

C类商品

3230个SKU

贡献5%销售额

优化措施

A类：每日监控库存，设置安全库存预警，优先补货
B类：每周盘点，采用定期订货策略
C类：批量采购，降低采购频次，减少管理成本

案例启示：通过ABC分类管理，该平台库存周转率提升了35%，库存资金占用降低了28%，实现了精细化运营。

五、ABC分类管理策略

各类别管理要点

管理维度 A类商品 B类商品 C类商品
库存检查 每日检查 每周检查 每月检查
订货策略 定量订货（小批量多批次） 定期订货 批量订货
安全库存 较高（避免缺货） 适中 较低
供应商管理 建立战略合作关系 保持良好关系 选择性价比高的供应商
预测精度 高精度预测 一般预测 简单预测

常见错误：很多企业只关注A类商品而忽视C类商品的管理。实际上，C类商品数量多，管理不当也会造成库存积压和资金浪费。应该简化而非忽视C类商品的管理。

解析：ABC分类法基于帕累托法则，即二八定律。该法则指出约20%的商品贡献约80%的销售额，这20%的商品应归为A类重点管理。

知识点测验

根据ABC分类标准，A类商品的累计销售额占比通常为？

50%-60%
60%-70%
70%-80%
80%-90%

解析：按照ABC分类标准，A类商品虽然品种只占10%-20%，但销售额贡献达到70%-80%，是需要重点管理的核心商品。
