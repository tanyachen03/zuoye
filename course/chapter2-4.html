一、数据清洗概述

为什么需要数据清洗

数据清洗是数据分析的第一步，也是最耗时的环节。据统计，数据分析师约60%-80%的时间花在数据清洗上。脏数据会导致分析结果偏差，甚至得出错误结论。

常见数据质量问题

缺失值 - 数据不完整，字段为空或NULL
重复值 - 相同记录出现多次
异常值 - 明显偏离正常范围的数据
格式不一致 - 日期、数字等格式混乱
数据类型错误 - 数值存储为字符串等
逻辑错误 - 数据之间存在矛盾

二、缺失值处理

检测缺失值

import pandas as pd import numpy as np # 创建含缺失值的数据 df = pd.DataFrame({ 'name': ['张三', '李四', None, '王五'], 'age': [25, np.nan, 30, 28], 'city': ['北京', '上海', '广州', np.nan], 'salary': [15000, 20000, np.nan, 18000] }) # 检测缺失值 print("缺失值检测:") print(df.isnull()) # 每列缺失值数量 print("\n每列缺失值数量:") print(df.isnull().sum()) # 缺失值比例 print("\n缺失值比例:") print((df.isnull().sum() / len(df) * 100).round(2)) # 查看含有缺失值的行 print("\n含缺失值的行:") print(df[df.isnull().any(axis=1)])

删除缺失值

import pandas as pd import numpy as np df = pd.DataFrame({ 'A': [1, np.nan, 3, np.nan], 'B': [5, 6, np.nan, 8], 'C': [9, 10, 11, 12] }) # 删除含有缺失值的行 df_drop_rows = df.dropna() print("删除含缺失值的行:") print(df_drop_rows) # 删除含有缺失值的列 df_drop_cols = df.dropna(axis=1) print("\n删除含缺失值的列:") print(df_drop_cols) # 只删除全部为缺失值的行 df_drop_all = df.dropna(how='all') # 至少有2个非缺失值才保留 df_drop_thresh = df.dropna(thresh=2) # 指定列判断 df_drop_subset = df.dropna(subset=['A', 'B'])

填充缺失值

import pandas as pd import numpy as np df = pd.DataFrame({ 'name': ['张三', '李四', None, '王五'], 'age': [25, np.nan, 30, 28], 'salary': [15000, 20000, np.nan, 18000] }) # 用固定值填充 df['name'] = df['name'].fillna('未知') # 用均值填充 mean_salary = df['salary'].mean() df['salary'] = df['salary'].fillna(mean_salary) # 用中位数填充 median_age = df['age'].median() df['age'] = df['age'].fillna(median_age) # 用前一个值填充（前向填充） df_ffill = df.fillna(method='ffill') # 用后一个值填充（后向填充） df_bfill = df.fillna(method='bfill') # 不同列使用不同填充值 df_fill = df.fillna({ 'name': '未知', 'age': df['age'].mean(), 'salary': df['salary'].median() }) print(df_fill)

小贴士：选择填充策略要考虑业务场景：数值型数据常用均值/中位数填充；时间序列数据常用前向/后向填充；分类数据常用众数填充。缺失比例过高（>50%）的列建议删除。

三、重复值处理

检测与删除重复值

import pandas as pd df = pd.DataFrame({ 'order_id': ['A001', 'A002', 'A001', 'A003', 'A002'], 'customer': ['张三', '李四', '张三', '王五', '李四'], 'amount': [100, 200, 100, 150, 200] }) # 检测重复行 print("重复行检测:") print(df.duplicated()) # 查看重复行 print("\n重复的行:") print(df[df.duplicated()]) # 删除完全重复的行 df_unique = df.drop_duplicates() print("\n删除重复后:") print(df_unique) # 基于指定列判断重复 df_by_order = df.drop_duplicates(subset=['order_id']) print("\n按order_id去重:") print(df_by_order) # 保留最后一个重复项 df_keep_last = df.drop_duplicates(keep='last') # 统计重复数量 print("\n重复数量:", df.duplicated().sum())

常见错误：删除重复时没有指定subset，导致只删除完全相同的行。实际业务中，通常需要根据关键字段（如订单ID、用户ID）判断重复。

四、异常值处理

异常值检测方法

异常值检测是数据清洗的重要环节，常用的方法包括统计方法、箱线图方法和业务规则方法。

import pandas as pd import numpy as np # 创建含异常值的数据 np.random.seed(42) df = pd.DataFrame({ 'age': [25, 28, 30, 32, 35, 150, 29, 31, -5, 33], # 150和-5是异常值 'salary': [8000, 12000, 15000, 18000, 20000, 500000, 16000, 17000, 14000, 19000] }) # 方法1：描述性统计 print("描述性统计:") print(df.describe()) # 方法2：箱线图方法（IQR） def detect_outliers_iqr(data, column): Q1 = data[column].quantile(0.25) Q3 = data[column].quantile(0.75) IQR = Q3 - Q1 lower_bound = Q1 - 1.5 * IQR upper_bound = Q3 + 1.5 * IQR outliers = data[(data[column] < lower_bound) | (data[column] > upper_bound)] return outliers, lower_bound, upper_bound outliers, low, high = detect_outliers_iqr(df, 'age') print(f"\nage异常值（范围: {low:.1f} - {high:.1f}）:") print(outliers) # 方法3：Z-Score方法 from scipy import stats z_scores = np.abs(stats.zscore(df['salary'])) outliers_zscore = df[z_scores > 3] print("\nsalary异常值（Z-Score > 3）:") print(outliers_zscore) # 方法4：业务规则 print("\n业务规则检测（年龄0-100）:") print(df[(df['age'] < 0) | (df['age'] > 100)])

异常值处理方法

import pandas as pd import numpy as np df = pd.DataFrame({ 'age': [25, 28, 30, 32, 35, 150, 29, 31, -5, 33], 'salary': [8000, 12000, 15000, 18000, 20000, 500000, 16000, 17000, 14000, 19000] }) # 方法1：删除异常值 df_clean = df[(df['age'] >= 0) & (df['age'] <= 100)] # 方法2：替换为边界值（Winsorization） df_cap = df.copy() Q1 = df_cap['salary'].quantile(0.25) Q3 = df_cap['salary'].quantile(0.75) upper = Q3 + 1.5 * (Q3 - Q1) df_cap.loc[df_cap['salary'] > upper, 'salary'] = upper # 方法3：替换为均值/中位数 df_replace = df.copy() mean_age = df_replace[(df_replace['age'] >= 0) & (df_replace['age'] <= 100)]['age'].mean() df_replace.loc[(df_replace['age'] < 0) | (df_replace['age'] > 100), 'age'] = mean_age # 方法4：标记异常值 df_flag = df.copy() df_flag['age_outlier'] = (df_flag['age'] < 0) | (df_flag['age'] > 100) print("标记异常值后:") print(df_flag)

小贴士：处理异常值前，先确认是数据错误还是真实的极端情况。对于明显的数据错误（如年龄-5），可以直接修正或删除；对于可能的极端情况（如超高收入），建议保留并标记。

五、数据格式标准化

字符串处理

import pandas as pd df = pd.DataFrame({ 'name': [' 张三 ', '李四', '王 五', '赵六 '], 'phone': ['138-1234-5678', '13912345678', '138 1234 5678', '137-1234-5679'], 'email': ['Zhang@Example.COM', 'li@test.com', 'WANG@TEST.CN', 'zhao@mail.com'] }) # 去除空格 df['name'] = df['name'].str.strip() # 统一电话格式 df['phone_clean'] = df['phone'].str.replace(r'[-\s]', '', regex=True) # 邮箱转小写 df['email'] = df['email'].str.lower() # 提取手机号前3位 df['phone_prefix'] = df['phone_clean'].str[:3] # 字符串分割 df['email_domain'] = df['email'].str.split('@').str[1] # 正则提取 df['phone_valid'] = df['phone_clean'].str.match(r'^1[3-9]\d{9}$') print(df)

日期处理

import pandas as pd df = pd.DataFrame({ 'date_str': ['2024/01/15', '2024-02-20', '2024.03.25', '2024/04/30'], 'datetime_str': ['2024-01-15 10:30:00', '2024-02-20 14:45:30', '2024-03-25 09:15:00', '2024-04-30 16:00:00'] }) # 转换日期 df['date'] = pd.to_datetime(df['date_str']) # 转换日期时间 df['datetime'] = pd.to_datetime(df['datetime_str']) # 提取日期组件 df['year'] = df['date'].dt.year df['month'] = df['date'].dt.month df['day'] = df['date'].dt.day df['weekday'] = df['date'].dt.day_name() df['quarter'] = df['date'].dt.quarter # 提取时间组件 df['hour'] = df['datetime'].dt.hour df['minute'] = df['datetime'].dt.minute # 日期计算 df['days_diff'] = (pd.Timestamp('2024-12-31') - df['date']).dt.days # 日期格式化 df['date_formatted'] = df['date'].dt.strftime('%Y年%m月%d日') print(df[['date', 'year', 'month', 'weekday']])

真实商业案例：客户数据清洗

背景：某公司CRM系统导出的客户数据存在多种质量问题，需要进行全面清洗后才能进行分析。

原始数据问题

  • 客户姓名存在空格、大小写不一致
  • 手机号格式不统一（有的带横线，有的带空格）
  • 注册日期格式混乱
  • 存在重复客户记录
  • 年龄字段存在异常值

清洗代码

import pandas as pd import numpy as np # 模拟原始数据 df = pd.DataFrame({ 'customer_id': ['C001', 'C002', 'C003', 'C001', 'C004'], 'name': [' 张三 ', '李四', '王五', '张三', '赵六'], 'phone': ['138-1234-5678', '13912345678', '138 1234 5678', '138-1234-5678', None], 'age': [25, 30, 150, 25, 28], 'register_date': ['2024/01/15', '2024-02-20', '2024.03.25', '2024/01/15', '2024-04-30'], 'total_purchase': [5000, np.nan, 8000, 5000, 3000] }) # 1. 去除姓名空格 df['name'] = df['name'].str.strip() # 2. 统一手机号格式 df['phone'] = df['phone'].str.replace(r'[-\s]', '', regex=True) # 3. 处理年龄异常值 df.loc[(df['age'] < 0) | (df['age'] > 120), 'age'] = np.nan df['age'] = df['age'].fillna(df['age'].median()) # 4. 统一日期格式 df['register_date'] = pd.to_datetime(df['register_date']) # 5. 去重（保留最后一条） df_clean = df.drop_duplicates(subset=['customer_id'], keep='last') # 6. 填充缺失的消费金额 df_clean['total_purchase'] = df_clean['total_purchase'].fillna(0) print("清洗后的数据:") print(df_clean)

清洗结果

通过系统化的数据清洗，将5条脏数据处理为4条干净数据，数据质量显著提升，可用于后续的客户分析和营销决策。

知识点测验

处理缺失值时，以下哪种方法不适合时间序列数据？

前向填充（ffill）
后向填充（bfill）
随机删除缺失行
线性插值

解析：时间序列数据具有时间连续性，随机删除缺失行会破坏时间序列的完整性。应该使用前向填充、后向填充或插值方法保持时间连续性。

知识点测验

使用IQR方法检测异常值时，异常值的判定范围是？

小于Q1或大于Q3
小于Q1-1.5*IQR或大于Q3+1.5*IQR
小于均值-标准差或大于均值+标准差
小于最小值或大于最大值

解析：IQR（四分位距）方法中，IQR = Q3 - Q1。异常值定义为小于Q1 - 1.5*IQR或大于Q3 + 1.5*IQR的值。这是箱线图中常用的异常值判定标准。
