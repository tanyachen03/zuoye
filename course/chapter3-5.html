本章综合案例

综合运用市场集中度、PEST、波特五力、SWOT四大分析框架，完成中国新能源汽车行业深度分析

案例目标

  • 综合运用本章所学的四种分析方法
  • 完成新能源汽车行业的完整分析报告
  • 掌握多框架整合分析的逻辑与方法
  • 形成基于数据的战略建议
  • 运用Python实现综合分析模型

案例背景：中国新能源汽车行业

案例简介

中国新能源汽车市场已成为全球最大的新能源汽车市场。2023年，中国新能源汽车销量达到949.5万辆，同比增长37.9%，市场渗透率达到31.6%。比亚迪、特斯拉、广汽埃安、理想、蔚来等品牌激烈竞争，行业格局快速演变。

本案例将从市场结构、宏观环境、竞争格局、企业战略四个维度，对中国新能源汽车行业进行全面分析。

# 新能源汽车行业集中度分析 import pandas as pd # 2023年中国新能源汽车市场数据 nev_data = { '企业': ['比亚迪', '特斯拉中国', '广汽埃安', '理想汽车', '五菱新能源', '蔚来汽车', '小鹏汽车', '其他'], '销量': [302.4, 94.7, 48.0, 37.6, 35.5, 16.0, 14.2, 401.1], '份额': [31.9, 10.0, 5.1, 4.0, 3.7, 1.7, 1.5, 42.2] } df = pd.DataFrame(nev_data) # 计算CR4和CR8 CR4 = df.head(4)['份额'].sum() CR8 = df.head(8)['份额'].sum() # 计算HHI HHI = (df['份额'] ** 2).sum() print("=== 市场集中度分析结果 ===") print(f"CR4 = {CR4:.1f}%") print(f"CR8 = {CR8:.1f}%") print(f"HHI = {HHI:.0f}") # 市场结构判断 print(f"\n分析结论：") print(f"1. CR4={CR4:.1f}%，属于中集中寡占型市场") print(f"2. HHI={HHI:.0f}，市场集中度中等偏高") print(f"3. 比亚迪一家独大，份额超30%") print(f"4. 头部企业集中度较高，但尾部竞争激烈")

分析结论：CR4=51%，属于中集中寡占型市场；HHI约1300，处于中等集中度水平。比亚迪以31.9%的市场份额领跑，形成"一超多强"格局。

# 新能源汽车PEST量化分析 import pandas as pd pest_data = { '维度': ['P', 'P', 'E', 'E', 'S', 'S', 'T', 'T'], '因素': ['双积分政策', '碳中和目标', '油价波动', '消费升级', '环保意识提升', '限购限行政策', '电池技术突破', '智能化发展'], '影响值': [5, 5, 4, 3, 4, 5, 5, 5], '概率': [95, 100, 70, 80, 85, 90, 85, 90] } df = pd.DataFrame(pest_data) df['得分'] = df['影响值'] * df['概率'] / 100 dimension_score = df.groupby('维度')['得分'].sum() total = df['得分'].sum() print("=== PEST分析结果 ===") print(dimension_score) print(f"\n综合得分: {total:.1f}") print("结论: 宏观环境整体非常有利")

# 波特五力量化分析 import pandas as pd five_forces = { '力量': ['潜在进入者', '现有竞争者', '供应商', '购买者', '替代品'], '权重': [0.2, 0.3, 0.15, 0.2, 0.15], '得分': [3, 5, 4, 4, 2] } df = pd.DataFrame(five_forces) df['加权'] = df['权重'] * df['得分'] competition_index = df['加权'].sum() print(f"行业竞争强度指数: {competition_index:.2f}") print("判断: 竞争较强，盈利压力较大")

分析结论：行业竞争强度指数3.7，属于竞争较强的行业。现有竞争者竞争是最关键的力量，价格战持续。供应商议价能力较强，锂价波动影响成本。

# 比亚迪SWOT量化分析 import pandas as pd byd_swot = { '类别': ['S', 'S', 'S', 'W', 'W', 'O', 'O', 'O', 'T', 'T'], '因素': ['垂直整合优势', '刀片电池技术', '成本控制能力', '高端品牌力不足', '海外布局较晚', '国内市场持续增长', '出口市场扩张', '智能化升级', '特斯拉降价竞争', '原材料成本波动'], '重要性': [5, 5, 4, 3, 3, 5, 4, 4, 5, 4], '评分': [5, 5, 4, -3, -2, 4, 4, 3, -4, -3] } df = pd.DataFrame(byd_swot) df['加权'] = df['重要性'] * df['评分'] summary = df.groupby('类别')['加权'].sum() net_score = summary.sum() print("=== 比亚迪SWOT得分 ===") print(summary) print(f"\n净战略得分: {net_score}") print("战略建议: SO增长型战略为主")

五、综合分析报告

综合分析结论

1. 市场结构

中国新能源汽车市场呈"一超多强"格局，CR4=51%属于中集中寡占型市场。比亚迪以31.9%份额领跑，但市场仍有较大竞争空间。

2. 宏观环境

PEST综合得分32分，宏观环境整体有利。政策支持（双积分、碳中和）和技术进步（电池、智能化）是核心驱动力。

3. 竞争格局

五力竞争指数3.7，竞争强度较高。现有竞争者竞争激烈，价格战持续；供应商议价能力较强，需关注原材料成本。

4. 战略建议

  • 头部企业：发挥规模优势，加速技术创新，拓展海外市场
  • 新势力：差异化定位，聚焦细分市场，提升品牌溢价
  • 传统车企：加快转型，发挥渠道优势，布局混动过渡
# 综合分析模型 - 整合四大框架 import pandas as pd class IndustryAnalyzer: def __init__(self, name): self.name = name self.results = {} def concentration_analysis(self, shares): """市场集中度分析""" df = pd.DataFrame({'份额': shares}) cr4 = df['份额'].head(4).sum() hhi = (df['份额'] ** 2).sum() self.results['CR4'] = cr4 self.results['HHI'] = hhi return cr4, hhi def pest_analysis(self, factors): """PEST分析""" df = pd.DataFrame(factors) df['得分'] = df['影响值'] * df['概率'] / 100 self.results['PEST'] = df['得分'].sum() return self.results['PEST'] def five_forces_analysis(self, forces): """波特五力分析""" df = pd.DataFrame(forces) df['加权'] = df['权重'] * df['得分'] self.results['五力'] = df['加权'].sum() return self.results['五力'] def swot_analysis(self, swot): """SWOT分析""" df = pd.DataFrame(swot) df['加权'] = df['重要性'] * df['评分'] self.results['SWOT'] = df['加权'].sum() return self.results['SWOT'] def generate_report(self): """生成综合报告""" print(f"=== {self.name} 行业分析报告 ===") print(f"市场集中度: CR4={self.results.get('CR4', 0):.1f}%, HHI={self.results.get('HHI', 0):.0f}") print(f"宏观环境得分: {self.results.get('PEST', 0):.1f}") print(f"竞争强度指数: {self.results.get('五力', 0):.2f}") print(f"战略得分: {self.results.get('SWOT', 0):.0f}") # 使用示例 analyzer = IndustryAnalyzer("中国新能源汽车") print("综合分析模型已构建完成")
