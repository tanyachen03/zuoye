一、Pandas DataFrame操作

创建DataFrame

DataFrame是Pandas中最核心的数据结构，类似于Excel表格，由行和列组成。

# 创建DataFrame的几种方式 import pandas as pd # 方式1：从字典创建 data = { '姓名': ['张三', '李四', '王五'], '年龄': [25, 30, 28], '城市': ['北京', '上海', '广州'] } df = pd.DataFrame(data) # 方式2：从CSV文件读取 # df = pd.read_csv('data.csv') # 方式3：从Excel文件读取 # df = pd.read_excel('data.xlsx') print(df)
知识点测验

在Pandas中，创建DataFrame的方式不包括以下哪一项？

从字典创建
从图片文件创建
从CSV文件读取
从Excel文件读取

解析：Pandas支持从字典、列表、CSV、Excel等多种数据源创建DataFrame，但不直接支持从图片文件创建。

数据选取与筛选

掌握DataFrame的数据选取方法是数据分析的基础技能。

# 数据选取与筛选 import pandas as pd # 创建示例数据 data = { '姓名': ['张三', '李四', '王五', '赵六'], '年龄': [25, 30, 28, 35], '城市': ['北京', '上海', '广州', '深圳'], '工资': [8000, 12000, 10000, 15000] } df = pd.DataFrame(data) # 选取列 print("=== 选取单列 ===") print(df['姓名']) # 选取多列 print("\n=== 选取多列 ===") print(df[['姓名', '工资']]) # 按条件筛选 print("\n=== 工资大于10000 ===") print(df[df['工资'] > 10000]) # 使用loc选取 print("\n=== 使用loc选取 ===") print(df.loc[1:2, ['姓名', '城市']])

二、数据清洗

处理缺失值

缺失值是数据分析中常见的问题，需要合理处理以避免影响分析结果。

# 处理缺失值 import pandas as pd import numpy as np # 创建含缺失值的DataFrame data = { '姓名': ['张三', '李四', np.nan, '赵六'], '年龄': [25, np.nan, 28, 35], '城市': ['北京', '上海', '广州', np.nan], '工资': [8000, 12000, 10000, 15000] } df = pd.DataFrame(data) # 查看缺失值 print("=== 缺失值统计 ===") print(df.isnull().sum()) # 方法1：删除含缺失值的行 df_drop = df.dropna() print("\n=== 删除缺失值后 ===") print(df_drop) # 方法2：填充缺失值 df_fill = df.copy() df_fill['年龄'] = df_fill['年龄'].fillna(df_fill['年龄'].mean()) df_fill['姓名'] = df_fill['姓名'].fillna('未知') print("\n=== 填充缺失值后 ===") print(df_fill)

处理异常值

异常值会严重影响数据分析结果，需要识别和处理。

# 处理异常值 import pandas as pd import numpy as np # 创建含异常值的DataFrame data = { '产品': ['A', 'B', 'C', 'D', 'E'], '销量': [100, 120, 95, 1000, 110], # 1000是异常值 '价格': [50, 60, 55, 500, 58] # 500是异常值 } df = pd.DataFrame(data) # 使用Z-score检测异常值 def detect_outliers(df, column): z_scores = np.abs((df[column] - df[column].mean()) / df[column].std()) return z_scores > 2 # 检测销量异常值 sales_outliers = detect_outliers(df, '销量') print("=== 销量异常值 ===") print(df[sales_outliers]) # 使用IQR方法处理异常值 def remove_outliers(df, column): q1 = df[column].quantile(0.25) q3 = df[column].quantile(0.75) iqr = q3 - q1 lower_bound = q1 - 1.5 * iqr upper_bound = q3 + 1.5 * iqr return df[(df[column] >= lower_bound) & (df[column] <= upper_bound)] df_clean = remove_outliers(df, '销量') print("\n=== 移除异常值后 ===") print(df_clean)

提示：处理缺失值和异常值时，需要结合业务背景，不能盲目删除或填充。了解数据产生缺失或异常的原因非常重要。

知识点测验

关于缺失值处理，以下说法正确的是？

必须删除所有含缺失值的行
缺失值只能用平均值填充
应结合业务背景选择合适的处理方式
缺失值对分析没有影响

解析：处理缺失值时应结合业务背景选择合适的方式，包括删除、填充等，而不是一概而论。

三、数据合并与连接

数据合并

数据分析中经常需要将多个数据源合并在一起进行分析。

# 数据合并 import pandas as pd # 创建两个DataFrame df1 = pd.DataFrame({ 'ID': [1, 2, 3, 4], '姓名': ['张三', '李四', '王五', '赵六'], '部门': ['销售', '研发', '销售', '研发'] }) df2 = pd.DataFrame({ 'ID': [1, 2, 3, 5], '工资': [8000, 12000, 10000, 9000], '入职日期': ['2022-01-01', '2021-06-01', '2022-03-15', '2023-01-01'] }) # 内连接 inner_join = pd.merge(df1, df2, on='ID', how='inner') print("=== 内连接 ===") print(inner_join) # 左连接 left_join = pd.merge(df1, df2, on='ID', how='left') print("\n=== 左连接 ===") print(left_join) # 右连接 right_join = pd.merge(df1, df2, on='ID', how='right') print("\n=== 右连接 ===") print(right_join)

数据拼接

当数据结构相同时，可以使用concat进行纵向或横向拼接。

# 数据拼接 import pandas as pd # 创建两个结构相同的DataFrame df_a = pd.DataFrame({ '日期': ['2024-01-01', '2024-01-02', '2024-01-03'], '销售额': [1000, 1200, 800], '订单数': [10, 12, 8] }) df_b = pd.DataFrame({ '日期': ['2024-01-04', '2024-01-05', '2024-01-06'], '销售额': [1500, 900, 1100], '订单数': [15, 9, 11] }) # 纵向拼接（合并行） df_concat = pd.concat([df_a, df_b], ignore_index=True) print("=== 纵向拼接 ===") print(df_concat) # 创建额外数据用于横向拼接 df_extra = pd.DataFrame({ '日期': ['2024-01-01', '2024-01-02', '2024-01-03'], '访客数': [100, 120, 80] }) # 横向拼接（合并列） df_merge = pd.concat([df_a, df_extra], axis=1) print("\n=== 横向拼接 ===") print(df_merge)

注意：在进行数据合并时，确保用于连接的键列具有相同的数据类型和格式，否则可能导致意外的结果。

知识点测验

在Pandas中，pd.merge()函数的how参数设置为'inner'表示什么连接？

内连接（只保留匹配的行）
左连接（保留左表所有行）
右连接（保留右表所有行）
全连接（保留所有行）

解析：how='inner'表示内连接，只保留两个表中键匹配的行。

四、数据类型转换

类型转换方法

正确的数据类型对于数据分析至关重要，需要掌握常用的类型转换方法。

# 数据类型转换 import pandas as pd # 创建DataFrame data = { '日期': ['2024-01-01', '2024-01-02', '2024-01-03'], '销售额': ['1000', '1200', '800'], '订单数': ['10', '12', '8'], '利润率': ['25%', '30%', '20%'] } df = pd.DataFrame(data) # 查看数据类型 print("=== 原始数据类型 ===") print(df.dtypes) # 转换日期类型 df['日期'] = pd.to_datetime(df['日期']) # 转换数值类型 df['销售额'] = df['销售额'].astype('int') df['订单数'] = pd.to_numeric(df['订单数']) # 处理百分比 df['利润率'] = df['利润率'].str.replace('%', '').astype('float') / 100 # 查看转换后类型 print("\n=== 转换后数据类型 ===") print(df.dtypes) print("\n=== 转换后数据 ===") print(df)
日期类型：pd.to_datetime()
数值类型：pd.to_numeric()
字符串类型：astype('str')
百分比处理：str.replace()
知识点测验

将字符串类型的日期转换为日期类型应使用哪个函数？

pd.to_numeric()
pd.to_datetime()
astype('str')
str.replace()

解析：pd.to_datetime()用于将字符串转换为日期时间类型。
